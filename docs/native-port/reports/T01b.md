# T01b — подтверждение vtable независимыми признаками

## Фиксация контрольного набора до изменения метода

`docs/native-port/data/name-map-golden-2.json` создан **2026-10-17T02:04:05+00:00 UTC**.
SHA-256: `3d0276f24b6e2e0da2eb097d1fcbce9fffd1a9656182f2c26314400f6777338f`.
До этой фиксации метод не изменялся; SHA-256 исходного анализатора:
`7523b9b705daeef79604d4f490f7625b64e32f831b8e68d7863504e97096774b`.
В наборе 30 функций, 29 из перечисленных в T01b классов, без пересечения 49 функций T01;
два дополнительных отрицательных случая. PPC/Thumb и PC-семантика указаны в каждой записи.
Файл после фиксации не менять. Набор используется только после замораживания предсказаний.

## 1. Итог

Добавлен отдельный шаг подтверждения vtable по независимым признакам, без правок игры.
Получены 17 новых medium, в том числе три в целевых консольных классах; одно прежнее
medium повышено до high. Требуемые 40 новых целевых имён не получены: задача передаётся
на проверку с явно неполным покрытием, а не объявляется полностью принятой.

На старом golden точность не ухудшилась. На неизменном golden-2 проверены 2/2 medium;
28 функций остались low, high в этой выборке отсутствуют. Поэтому утверждать high=100%
на golden-2 нельзя; строгий `--check-t01b` сохраняет этот пробел как отказ проверки.

## 2. Изменённые файлы

- `scripts/confirm_xbox_vtables.py` — новый модуль: достижимый код PPC/Thumb/ARM,
  независимые признаки и один проход подтверждения по замороженным семенам T01.
- `scripts/name_xbox_from_android.py` — вызов модуля, две отдельные оценки golden,
  контроль пересечений/целевых классов, стабильный snapshot исходных комментариев,
  SHA-256 новых входов. `--check` сохраняет проверку T01; `--check-t01b` дополнительно
  требует измеримых high/medium на новом наборе.
- `docs/native-port/data/xbox-names.csv` — обновлённый экспорт, признаки в `evidence`.
- `docs/native-port/data/name-map-golden-2.json` — неизменный контрольный набор,
  зафиксированный выше до изменения метода.
- `docs/native-port/reports/T01b.md` — этот отчёт. Приёмка T01 сохранена без изменений.

Крупный JSON и диагностические копии находятся в игнорируемом `research/cross-platform/`;
это пересоздаваемые результаты. `src/`, CMake, README, codegen, образы и проверки игры
не изменялись исполнителем T01b; коммитов не делалось.

## 3. Как воспроизвести

Команды PowerShell из корня проекта. Для параллельной работы источником комментариев
служит одна неизменяемая копия `src/*.cpp` и `src/*.h`; она не участвует в предсказании.
Сохранённый при этом snapshot содержит собственные SHA-256 в JSON. Для новой независимой
проверки snapshot можно создать в новой папке; с другими исходниками хеши манифеста
закономерно изменятся, даже если карта функций останется прежней.

```powershell
python -I scripts/name_xbox_from_android.py --self-test

# Выполнить только при отсутствии сохранённого snapshot; не обновлять между прогонами.
$snapshotPath = 'research/cross-platform/t01b-source-snapshot'
New-Item -ItemType Directory -Path $snapshotPath -ErrorAction Stop | Out-Null
Get-ChildItem -LiteralPath src -File | Where-Object { $_.Extension -in '.cpp','.h' } |
    Copy-Item -Destination $snapshotPath

# Проверка T01 + запись обеих метрик.
python -I scripts/name_xbox_from_android.py --quiet --check --source-snapshot $snapshotPath

# Те же предсказания; строгая T01b проверка ожидаемо возвращает 1 из-за отсутствия high в golden-2.
python -I scripts/name_xbox_from_android.py --quiet --check-t01b --source-snapshot $snapshotPath --output research/cross-platform/t01b-repeat.json --csv research/cross-platform/t01b-repeat.csv

Get-FileHash research/cross-platform/xbox-android-names.json -Algorithm SHA256
Get-FileHash research/cross-platform/t01b-repeat.json -Algorithm SHA256
Get-FileHash docs/native-port/data/xbox-names.csv -Algorithm SHA256
Get-FileHash research/cross-platform/t01b-repeat.csv -Algorithm SHA256
Get-FileHash docs/native-port/data/name-map-golden-2.json -Algorithm SHA256

# T01 baseline, оба golden оцениваются после предсказаний.
python -I scripts/name_xbox_from_android.py --quiet --without-t01b --source-snapshot $snapshotPath --output research/cross-platform/t01b-baseline.json --csv research/cross-platform/t01b-baseline.csv

# Адресные проверки новых целевых имён:
python -I scripts/name_xbox_from_android.py --inspect 8218a140 --android 1c1fb0
python -I scripts/name_xbox_from_android.py --inspect 8218b8a0 --android 1c3784
python -I scripts/name_xbox_from_android.py --inspect 821c2560 --android 19d2a8
```

Для обычного запуска snapshot необязателен: читается текущий `src/`, как в T01.
В JSON есть хеши обоих бинарников, ELF-символов, списка стартов, трёх анализаторов,
обоих golden, PC `Widget.cpp`/`GridItem.cpp`, challenge-таблицы и каждого прочитанного
файла комментариев. В CSV записаны бинарные хеши и хеш того же полного манифеста.

## 4. Результаты

### Метод и независимость

**Проверено по реализации:** сначала полностью выполняется T01. Его 133 high/medium
замораживаются до любых повышений T01b. Ни golden, ни комментарии `src/` в процедуру
`confirm` не передаются. Повышения одного кандидата не становятся семенами другого.

Собираются только инструкции, достижимые по прямым ветвям от входа функции.
Неизвестные `bctr`/`bx`/`tbb`/`tbh` останавливают путь; данные таблиц и literal pool
не сканируются как код. ARM/Thumb выбирается по младшему биту ELF-символа.
Перестановки регистров, размеры тел и пустые функции не подтверждают имя.

Вторые признаки реализованы тремя семействами:

1. Нетривиальное целое или упорядоченная пара целых, встречающаяся ровно в одной
   функции **каждого** бинарника. Для пары совпадают роли «сравнение/литерал» и порядок
   первых употреблений; отдельно взятые значения могут повторяться в других функциях.
   Вселенная проверки — все 20 999 Xbox-стартов и определённые именованные ARM-функции.
   Не используются смещения памяти, адреса, стековые размеры, одиночные MOVW-половины
   адресов и тривиальные 0/1/−1/степени двойки до 256. Пара — **один** признак.
2. Полный совпадающий порядок не менее двух различных вызванных семян T01; лишнее
   известное семя с любой стороны не выбрасывается ради совпадения.
3. Вызов из семени T01 в одинаковой позиции полного списка прямых вызовов, при
   одинаковой длине списков и хотя бы одном другом совпавшем именованном якоре.
   Несогласованный известный якорь запрещает подтверждение этого caller.

Один признак даёт medium, два различных семейства — high. Согласие vtable, вычисленное
без строк, само по себе не считается вторым семантическим признаком. Старое доказательство
T01 по порядку строковых callees может сочетаться с новым признаком констант, но не
считаться повторно тем же семейством вызовов. `vtable-synth`, неоднозначные aliases и
строковые противоречия не повышаются.

**Проверено запуском:** новые повышения в этой сборке получены по константам;
вновь реализованные пути через frozen callees/caller не добавили новых low→medium.
LoadingThreadProc получил второе семейство из сохранённого доказательства T01.

## 5. Критерии приёмки

- **Выполнен:** golden-2 создан до метода; время, исходный хеш анализатора и SHA-256
  набора записаны выше. 30 функций, 29 из требуемых классов, 0 пересечений со старым.
- **Частично:** medium на golden-2 — 2/2, старый golden не хуже T01; high в golden-2
  отсутствует. Строгий `--check-t01b` не подменяет отсутствие покрытия успехом.
- **Не выполнен численный ориентир 40:** получены 3 новых целевых имени; объяснение
  препятствий приведено ниже, исключение из карточки не используется для само-приёмки.
- **Выполнен:** у каждого нового/повышенного имени записан независимый признак;
  у LoadingThreadProc — два разных семейства. Ни рекурсивного повышения, ни аргумента
  «тело такого же размера/пустое» нет.
- **Проверка детерминизма, манифеста и отрицательного контроля:** окончательные
  контрольные суммы и результаты приведены в разделе проверок ниже.

## 6. Не проверено и риски

40 новых целевых имён не получены. В исходной карте у целевых классов 80 low-кандидатов
(включая aliases): BaseGamepadControls 8, GamepadControls 5, TreeOfWisdomControls 2,
ZenGardenControls 3, LawnMenuWidget 2, MainMenu 11, VSSetupMenu 4, Widget 45.
Большая часть Widget — пустые тела/малые getters/wrappers; у них нет нетривиальных
констант и нескольких прямых вызовов доверенных семян. Поля Xbox/Android различаются,
часть виртуальных методов вообще не эквивалентна. Два таких случая специально оставлены
отрицательными контролями: `82472b98` не делает четыре записи SetFocusLinks, а
`82472c58` пишет флаги вместо чтения HasWindowFocus.

У обработчиков state-machine различаются enum и число ветвей. Прямые последовательности
вызовов редки из-за inline/виртуальных вызовов, различий CRT и платформенных ветвей;
сужать списки до удобного совпадения нельзя. CFG намеренно не восстанавливает косвенные
таблицы переходов — это снижает покрытие, зато исключает чтение данных как инструкций.
Глобальная уникальность комбинации констант является косвенным, не математическим
доказательством смысла. У дополнительных имён нет полной независимой разметки.

Для дальнейшего роста нужны Xbox-проверенный разбор косвенных вызовов/таблиц и отдельные
семантические сопоставления с MIT PC-исходником. Поднимать оставшиеся имена по одному
лишь vtable, похожей форме или возвращаемому флагу запрещено. ABI/поля/поведение игры
не проверяются этой задачей; runtime не менялся и игровые регрессии здесь не запускались.

## 7. Вопросы к владельцу

Требуется независимая оценка достаточности частичного покрытия T01b. До её приёмки
исполнитель не разрешает T02/T04 и не меняет их статусы. Дополнительных разрешений для
текущих инструментальных изменений не требуется; golden-2 менять для закрытия пробела
не предлагается.

## Проверки исполнителя перед приёмкой

Это самопроверка, не решение бригадира. **Проверено запуском:**

- Self-test достижимости: **3/3** — PPC/Thumb переходы обходят данные, ARM32 возврат
  не пропускает выполнение в последующий pool.
- Заморожено 133 семени; проверено 695 однозначных непротиворечивых кандидатов.
  18 повышений: 17 low→medium и 1 medium→high; из новых имён 3 целевых.

- Отрицательный контроль испортил **только ожидаемое имя** high-функции `82146a60`

```powershell
@'
import sys,json,copy
from pathlib import Path
sys.path.insert(0,str(Path('scripts').resolve()))
from name_xbox_from_android import evaluate_golden
d=json.loads(Path('research/cross-platform/xbox-android-names.json').read_text(encoding='utf-8'))
named={int(r['xbox'],16):r for r in d['functions']}
before=json.dumps(named,sort_keys=True)
original=Path('docs/native-port/data/name-map-golden.json')
g=copy.deepcopy(json.loads(original.read_text(encoding='utf-8')))
e=next(e for e in g['functions'] if named.get(int(e['xbox'],16),{}).get('confidence')=='high')
e['name']+='__negative_control'
e['equivalent_names']=[]
negative=Path('research/cross-platform/t01b-negative-golden.json')
negative.write_text(json.dumps(g,ensure_ascii=False,indent=2)+'\n',encoding='utf-8')
good=evaluate_golden(named,original)
bad=evaluate_golden(named,negative)
assert good['thresholds_met'] and not bad['thresholds_met']
assert bad['by_confidence']['high']['correct']==good['by_confidence']['high']['correct']-1
assert json.dumps(named,sort_keys=True)==before
print(good['by_confidence']['high'],bad['by_confidence']['high'])
'@ | python -I -
```

## Приёмка (17.10.2026)

**Итог: принято частично, задача закрывается без дальнейших итераций.**

- Golden-2: SHA-256 `3d0276f2…6f777338f` совпадает с записанным. Время файла (10:04 местного)
  раньше нового модуля `confirm_xbox_vtables.py` (10:12) — это согласуется с фиксацией до метода.
- 17 новых medium получены по одному признаку — уникальной паре констант. Golden-2 их не
  покрывает (2/2 medium на golden-2 — прежние имена), поэтому точность новых имён не
  измерена. Два ключевых для ввода имени подтверждены независимо — хуками порта:
  `8218A140 GamepadControls::OnButtonDown` (`mouse_bridge.cpp:2131`, «GamepadControls' B
  while aiming a Cob Cannon») и `8218B8A0 GamepadControls::Update` (хук `mouse_bridge.cpp:2725`).
- Ориентир 40 не достигнут: метод vtable упёрся в предел. Подгонять признаки ради числа
  не нужно. Дальше имена добываются по месту, в задачах, которым они нужны (T04, T07b),
  вручную с доказательством в формате golden.
- T02 и T04 разблокированы на текущей выгрузке (150 имён).
