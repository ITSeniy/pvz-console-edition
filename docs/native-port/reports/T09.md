Из корня проекта; используются **уже установленные** Python/NumPy/Pillow и FFmpeg,
никаких загрузок или установок не требуется:

```powershell

& 'C:/Users/ITSeniy/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' -I scripts/inventory_native_assets.py --ffmpeg C:/ProgramData/chocolatey/lib/ffmpeg/tools/ffmpeg/bin/ffmpeg.exe --test-xctd-tool *> runtime-data/t09-inventory.log

# Проверка адресов загрузки SaveGame, без записи образов:
python -I scripts/name_xbox_from_android.py --inspect 82205890 --android 00143B65
python -I scripts/name_xbox_from_android.py --inspect 82204678 --android 001426B1
python -I scripts/name_xbox_from_android.py --inspect 824B62F0 --android 002F7CE5

Get-FileHash scripts/inventory_native_assets.py,research/cross-platform/native-assets/inventory.json -Algorithm SHA256

```

На проверенном окружении: Python **3.12.14**, NumPy **2.3.5**, Pillow **12.3.0**,
FFmpeg **8.1 essentials**. Изолированный системный Python без NumPy можно использовать
с `--sample 0`, но это **не** повторяет проверку содержимого аудио.
Нужны существующие Xbox decoded-кэши с `.pak.meta.json` и исходные инвентари.
`--test-xctd-tool` запускает существующий research-ripper; его ожидаемые отказы
на двух пакетах регистрируются в JSON, а не скрываются как успешная распаковка.

Снимок SHA-256 текущего результата:

| Файл | SHA-256 |
|---|---|
| `scripts/inventory_native_assets.py` | `bbf78e5f7cf6438d8d5c6e2448f0ce5500d31c4058a25257a9958cd366aa64a7` |
| `research/cross-platform/native-assets/inventory.json` | `1f06d36b0f98f09c690987302428a2584555b26f1bea2ce78dec190015bfae56` |

JSON содержит `input_sha256` выбранных входов, бинарников инструментов и самого
анализатора; `immutable_trees_before` — хеш каждого файла в четырёх входных деревьях.
После чтения деревья хешируются повторно; `inputs_unchanged=true`.
При финальной сверке все **256** хешей `input_sha256` и все записанные хеши
деревьев снова совпали с файлами на диске: `assets` — **37**, Android — **1684**,
`save` — **6**, runtime user — **8** файлов. Это числа текущих файловых деревьев,
а не число ресурсов PAK или записей APK-инвентаря.
SHA JSON может отличаться при смене абсолютного пути FFmpeg или версии окружения;
это не повод изменять ожидания игровых данных.

Важные уточнения к прежним предположениям:

- 195 совпавших имён **не доказывают** равенство 195 звуков. У `tapglass`
  различие длительности почти 0,2 с, у `plant2` существенно ниже корреляция;
  mono-проекция не проверяет стереоканалы.
- Android имеет английскую финальную песню в `sounds/`; предыдущий поиск только
  в `music/` её пропускал. Оба английских Ogg отличаются encoded SHA; содержимое
  песни не сравнивалось. Три Xbox XM нельзя называть тремя отдельными мелодиями.
- Наличие LZX-библиотеки не закрывает XCTD-framing и CRC. Текущий отдельный
  research-ripper непригоден как готовая замена QuickBMS для `main.pak`.
- Xbox SaveGame содержит mixed-endian оболочку: в одном предоставленном образце
  проверены SHA-1 тела, LE длина header 12, BE magic/version 8. Xbox loader
  `0x82205890` принимает version 8; PC-код требует version 2 и build-date.
  Android loader также требует 8, но это не доказывает совместимость raw-объектов.

**Косвенный вывод:** большинство эффектов выборки имеют общее происхождение,
но Android-ресурсы нельзя считать полной заменой Xbox-копии. Для собственного
нативного пути ещё нужны настоящие readers/decoders, перечисленные в `assets.md`.

## 5. Критерии приёмки

- **Выполнен:** каждый тип файла Xbox-инвентаря в таблице — 13 расширений,
  4104 package-qualified записи. Назначение, фактическая проверка и отсутствие
  полного парсера для неизвестных форматов указаны явно; loose Xbox-файлы описаны отдельно.
- **Выполнен:** скрипт проверил все **195** пар по метаданным и **20 ≥ 10**
  по декодированному содержимому. Критерий проверки выполнен; гипотеза полного
  равенства звуков не подтверждена, расхождения сохранены без ослабления метрик.
- **Выполнен:** нет записи в `assets/` и образы игр. Полные SHA-256 снимки
  `assets`, Android-образа, `save`, `runtime-data/user` до/после совпали;
  исходные PAK/decoded-кэши и справочники только читались. Производные файлы
  находятся в отдельном research-каталоге.

## 6. Не проверено и риски

- Полная семантика 308 `.compiled`, XML-диалекта, шрифтов, OLE и tracker-модулей
  не реализована. Успешная сигнатура/текст/базовое изображение — частичная проверка.
- Остальные 175 XMA не декодировались; полный stereo/спектральный анализ,
  прослушивание и сравнение музыки не выполнялись. Предупреждения FFmpeg сохранены.
- CRC XCTD неизвестен; 20-битная таблица и произвольные варианты flags не проверены.
  Не исправлялись ошибки существующего ripper на main/jp.
- Полный Board SaveGame и profile layout не восстановлены, ZAR не распакован,
  реального Android SaveGame для round-trip нет. Совпадение version 8 недостаточно
  для бинарной совместимости. Перенос сохранений не реализован.
- Код сторонних декомпиляций/модов или libmspack в порт не копировался;
  лицензирование будущих декодеров остаётся отдельным решением.
- Игровая сборка и регрессии повторно не запускались: T09 меняет только
  исследовательский анализатор и документацию. Self-test проверил границы RIFF,
  число PCM-сэмплов и восстановление известного сдвига 137 сэмплов в корреляции.
