# T17. Пакеты B008, B014, B018: диалоги, кнопки, поле ввода

**Этап:** пакеты замен · **Зависит от:** T16 (принята) · **Объём:** средний · **Меняет поведение игры:** только под флагами

## Цель

Перенести элементы интерфейса поверх уже перенесённого каркаса Widget (B001, B003, B005,
B013): диалоги, кнопки, ползунки, флажки и поле ввода. Порядок работы — как в доработке
T16: всё реализовать, измерить охват, затем одно общее доказательство.

## Что сделать

1. **Хронометраж.** Включить таймер до чтения первого тела. Отдельно учитывать каждый
   пакет, внутри пакета — заглушки (≤ 8 байт) и остальные функции.
2. **Реализация всех 130 функций** без существующих хуков, по `replacement-howto.md`.
   - Файлы `src/native/b008_dialog.cpp`, `b014_buttons.cpp`, `b018_edit_widget.cpp`.
   - Флаги `--pvz_native_b008`, `b014`, `b018`.
   - Вызовы — через `guest_call.h`.
   - Оформление — `clang-format` по `src/native/.clang-format`.
   - Обёртки `FORWARD` и вызовы `__imp__sub_…` запрещены (`agent-guide.md`, §3); runner их
     отвергает.
   - Новые поля — в `src/xbox/*.h` со `static_assert` и доказательствами в
     `data/xbox-layouts.csv`.
3. **Измерение охвата** — сразу после реализации, до выбора флагов пакета.
   - `-Discover` для `b008+b014+b018`: каждая функция включена своим флагом.
   - Пять сценариев и дополнительные реплеи из п. 4.
   - В CSV записать наблюдённые вызовы. Под флаг пакета идут функции с ненулевым охватом,
     а также листовые, доказанные синтетикой.
4. **Охват.** Готовые реплеи, новые не записывать:
   - B008: `game_settings.csv`, `services_quit_confirm.csv`, `services_settings_pad.csv`;
   - B014: `menu_panels.csv`, `menu_panels_actions.csv`, `audio_settings.csv`,
     `minis_chooser_ui.csv`, `oct7_chooser.csv`, `input_ownership.csv`;
   - B018: поле ввода, вероятно, только в имени профиля. Если реплея с ним нет —
     функции остаются `unproven` с причиной «нет охвата», реализация остаётся.
5. **Рисующие функции** (`Draw` кнопок, ползунков, флажков, диалога, поля ввода) —
   `SnapshotsOnly` с трассой Graphics.
   - Трассу снимать на реплее, где функция действительно рисует. Механизм
     `extra_render` из T16 расширить на список реплеев, а не на один `services_almanac`.
   - Если функция не попадает ни в одну трассу, под флаг пакета она не идёт.
6. **Комбинации флагов** — как в T16: без флагов (два прогона), три новых пакета, все
   десять пакетов (B001–B003, B005, B008, B010, B013, B014, B017, B018).
7. **Таблица** `native-replacements.csv`: строки трёх пакетов со статусом, видом
   доказательства и измеренным охватом.

  перечислить каталоги, где они созданы.
