# T11 — классы Xbox и план пакетов (пересчёт T11b)

## 1. Итог

Карта содержит 20999 функций: high 1101, medium 581, low 458, unknown 18859. План: 54 пакетов; отдельный список unassigned: 8920 функций. Поведение игры не менялось.

Сильные назначения T11 сохранены: 1 358 пар адрес/класс/уровень; fingerprint `7575535ffde9c2e94161cc3971a2ee23ce29c5b2d6094c21713beb74f135200a`. Проверяется validate() независимо от выходного CSV.

## 2. Изменённые файлы

- `scripts/classify_xbox_functions.py` — PPC/RTTI, T04, замыкание, сверка имён, план и проверка.
- `docs/native-port/data/xbox-function-classes.csv` — компактные восемь колонок, без JSON.
- `docs/native-port/data/replacement-batches.csv` — непересекающиеся пакеты с причинами порядка.
- `docs/native-port/reports/T11.md` — этот воспроизводимый отчёт.
- `docs/native-port/reports/T11b.md` — ручной отчёт и новая выборка исполнителя.
- `research/function-classes/full-analysis.json` — полные записи с доказательствами, вне git.
- `research/function-classes/library-zones.json` — корни библиотек и границы, вне git.

## 3. Как воспроизвести

```powershell
python -I scripts/classify_xbox_functions.py --self-test
python -I scripts/classify_xbox_functions.py
python -I scripts/classify_xbox_functions.py --check --sample
python -I scripts/classify_xbox_functions.py --review-context medium --review-offset 0
# Повторить --review-offset 5, 10, 15; затем те же четыре команды для low.
python -I scripts/classify_xbox_functions.py --inspect 8212C540
```

Capstone: локальный tools/python, Android extractor: name_xbox_from_android.py. --check пересчитывает оба CSV, оба research JSON и отчёт, требует побайтного совпадения и ничего не пишет. Если research отсутствует, сначала нужен обычный запуск. --review-context читает полные доказательства из full-analysis.json.

### Метод и ограничения достоверности

- **high / проверено Xbox:** прежние RTTI-vtable и принятые имена T01/T01b.
- **medium / подтверждено косвенно:** сохранённые T11; новый класс по всем статическим call sites с одинаковым r3 (двое разных H/M callers), либо по проверенному полю T04; либо уникальная полная сигнатура из двух и более смещений с шириной доступа и отдельным H/M caller с разрешённым r3 того же класса (signature_support).
- **low / гипотеза:** единственный identity-caller или цепочка, содержащая low. Неподтверждённая сигнатура также low. Low не превращается в medium за счёт количества своих потомков, циклы low не подтверждают себя.
- **unknown:** конфликт либо недостаток данных. Непрояснённый caller блокирует назначение по вызовам. Саморекурсия не даёт второго caller.

Типы указательных полей перечислены в FIELD_TYPES; смещения, форма массива и Xbox-доказательство загружаются из T04. Нет типа по одному лишь GuestPtr. Выражения this+N и secondary-vtable учитываются: для нового класса нужен нулевой итоговый adjustment, неоднозначный adjustment блокирует вывод. Поля отсчитываются от полного объекта. В research указаны call site, caller, r3-origin и цепочка загрузок полей.

PPC: пересечение на слияниях, уничтожение volatile после обычных вызовов. Store-only save helpers GPR/FPR проверяются по каждому PPC-слову до blr, включая внутренние точки входа общей процедуры, и сохраняют r3. Нет типов возвращаемых значений, stack spills, динамических целей и восстановления jump tables. Возможна недооценка охвата. Сигнатуры уникальны в наблюдаемом корпусе, а не во всей возможной программе; это косвенный признак. Противоречащие им типизированные callers оставляют функцию unknown/conflict, и замыкание строится заново. Новые прямые записи vtable дают дополнительные Xbox-якоря без потери исходных T11.

Замыкание: `{"new_vtable_store_anchors":124,"rounds":12,"signatures_proposed":379,"signatures_rejected":7}`.

## 5. Критерии приёмки

- Новая выборка 20 medium: seed 2026101802; протокол в T11b.md.
- validate(): нет библиотек в пакетах/сигнатурах; medium-сигнатуры имеют signature_support.
- Охват >=50% оценивается по таблице game выше; если меньше — частичная приёмка, остаток разобран по причинам.
- Новые назначения содержат инструкции, callers либо сигнатуру с независимыми Xbox-примерами.
- validate(): пакеты без unknown, без пересечений; у всех есть order_reason.
- --check сверяет оба CSV, оба research JSON и отчёт побайтно; все 1 358 прежних high/medium сохранены.

## 6. Не проверено и риски

Полнота графа, ABI и эквивалентность будущих нативных замен не доказаны. Сигнатуры и контекст r3 могут относиться к free helpers или общей базовой реализации. Изолированные функции библиотек без roots/calls/callback-ссылок могут остаться неизвестными. Новая ручная выборка — в T11b.md. Эти таблицы требуют проверки перед нативной заменой. Неизвестные indirect-only цели нельзя строго отделить от мёртвого/экспортируемого кода: метка indirect-target-possible показывает лишь наличие адресных ссылок. Игра и сборка не запускались.
