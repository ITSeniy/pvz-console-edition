# Проверка мыши 8 октября 2026

Добавлены перенос карточек и лопаты с применением при отпускании,
повторный клик для снятия выбора, проверка актуальности ленты и отмена
захвата при потере фокуса с выключенной автопаузой. Исправлены ложный
силуэт над панелью и перехват кликов скрытым SeedChooser в Slot Machine.

Сборка: `build.bat`; CTest: **4/4**. Проверка игровых действий:
`scripts/check_item_drag.py`, отчёт `runtime-data/item-drag-validation.json`.
Результат анализатора: **30/30**.

| Сценарий | Проверенные действия |
| --- | --- |
| Wall-nut Bowling | Перенос с посадкой только на Up; два клика; toggle; быстрые Down/Up в одном кадре; отпускание на нижней границе панели. |
| Отмена | ПКМ, выход из окна, смена PC/Console, потеря фокуса без автопаузы, контроллер. Нет запоздалой посадки после отмены. |
| Обучение лопате | Перенос через область вне газона, применение на Up; два клика; Console с удержанием ПКМ; переход 17 → 18 и продолжение Дэйва. |
| Zombotany | Набор с Imitater и LET’S ROCK!; перенос обычной карточки; силуэт только на газоне; отказ по цене со звуком. |
| Slot Machine | Рычаг; подбор выпавшего пакета; отпускание без посадки тем же жестом; посадка следующим кликом; продолжение импортированного раунда. |
| Zombi-quarium | Покупка рыбки за штатную цену и отдельные клики корма; покупки не создают жест посадки. |

Журналы и кадры проверяют отдельные игровые действия. Полное прохождение
мини-игр, продолжительная игра в Survival, кооператив и физические контроллеры
не входят в этот прогон. Добавление карточек справа на ленте допускается;
изменение данных до выбранного слота отменяет выбор. Нативный сдвиг ленты
после использования проверен в Bowling; внешнее изменение банка во время
жеста отдельно не воспроизводилось.

Все прогоны используют новый профиль либо копию тестового профиля.
Исходное сохранение мини-игр и обычный профиль не изменялись.
