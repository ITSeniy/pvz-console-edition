- run_native_proof.ps1 получает пакеты/файлы из src/native/b0NN_*.cpp; дубликаты

- Для защиты общих generated-входов локальный build.ninja вызывает SHA-проверку
  вместо codegen. Исходники CMake/codegen и общие входы не менялись. После
  configure.cmd применяется freeze-codegen.py. Это локальная настройка build/.
- Неуспешные compile/configure логи сохранены. Discovery-1 выявил штатный quit
  с кодом 0: только services_quit_confirm допускает ожидаемый выход, при обязательных
  readiness/completion и отсутствии fatal. В остальных replay survival обязателен.
  Quit не используется для фиксированной Graphics-трассы, поскольку завершает процесс.
- Два ранних render-preflight остановились на null в новом driver: пустой switch
  список флагов оказался null. Исправлен список, завершённые неизменные процессы
  повторно сверены по EXE/scalar flags/receipt/log/dump/trace SHA. Затем все три
  discovery-render доказательства прошли. Отрицательные результаты не удалялись.
- Первая unit-команда обнаружила относительный поиск src/native из build/;
  исправлен путь скрипта, повторная команда 29/29. EXE не менялся.
- Снимки доказывают наблюдаемые домены T08; Graphics-трассы не являются сравнением

  слышимое аудио и субъективная плавность не объявляются доказанными.
- Итоговый CSV дополнен ссылками после proof. Его gates совпадают с неизменным
