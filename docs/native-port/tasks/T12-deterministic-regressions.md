# T12. Воспроизводимые штатные регрессии

**Этап:** инструменты проверки · **Зависит от:** T05b, T05c, T10 (приняты) · **Объём:** средний · **Меняет поведение игры:** нет

## Цель

Пакеты нативных замен будут проверяться штатными регрессиями после каждого переноса.
Сейчас их итог на одном и том же EXE меняется от прогона к прогону. Новую ошибку от случайного
отказа так не отличить. Нужно, чтобы одинаковый EXE давал одинаковый набор пройденных и
непройденных проверок.

## Что известно

Регрессии (`scripts/run_{feedback,multiplayer,services,shop}_regression.ps1`) запускают
`smoke.ps1` с секундными реплеями. Источники разброса:

- **RNG:** seed от времени (`822CA100` → `824943A0`, разбор T05b). Отсюда раскладка ваз
  (`vases_pc_explicit_seed`, `vases_pc_place_seed`) и падающее солнце. В
  `mouse_player_two_places` 18.10 щелчок посадки попал в солнце: `board hit type 3`, `clicked
  coin pickup` в `logs/smoke-20261018-163005-700.log`.
- **Доставка ввода:** реплей идёт по настенным часам отдельным потоком. Даже при
  фиксированном seed число логических шагов до события, а значит и число вызовов RNG до него,
  может меняться.
- **Часы Zen:** `time32` (решено флагом T05c `pvz_deterministic_clock`).
- **`pc_settings_back`:** ускоренный автоповтор геймпада. Его исправляет флаг T07b
  `pvz_gamepad_repeat_fix`, но он меняет поведение игры, а включение по умолчанию — решение
  владельца. В рамках T12 флаг **не включать**: проверка остаётся известной до этого решения.

## Что сделать

1. **Замер.** На текущем `master` три полных прогона четырёх наборов. Таблица: проверка →
   исходы по прогонам. Это база разброса.
2. **Seed и часы.** Добавить в четыре runner режим `-Deterministic`: `--pvz_deterministic_seed`
   и `--pvz_deterministic_clock` с фиксированными значениями, записанными в результат прогона.
   Три полных прогона. Если отличающихся проверок нет — перейти к п. 4.
3. **Доставка по шагам.** Для сценариев, где разброс остался, записать пошаговые реплеи тем
   же путём, что в T05b/T10 (`--pvz_replay_record_steps`, `replay_seconds_to_steps.py`).
   Сохранить их в `tests/replays/regression-steps/` с JSON конвертации. В
   детерминированном режиме runner берёт их с `--pvz_replay_frame_locked=true`. Секундные
   реплеи не менять.
4. **Режим по умолчанию.** Детерминированный режим — по умолчанию для всех четырёх runner.
   Прежний режим доступен ключом `-WallClock`: он ближе к живой игре и нужен для ручных
   проверок. Записывать режим и его параметры в `*-regression-runs.json`, чтобы checker и
   отчёт видели, как шёл прогон.
5. **Снимки кадров.** Часть проверок смотрит кадры `--pvz_capture_*`, снятые по настенным
   секундам. Если такие проверки остаются нестабильными, выяснить причину. Проверку при этом
   не ослаблять: перенос момента снимка на логические шаги — только с обоснованием в отчёте.

## Правила

- Ожидания в `scripts/check_*` не менять.
- Если в детерминированном режиме проверка стабильно не проходит из-за артефакта сценария
  (как солнце под щелчком), не двигать щелчок и не подбирать seed под проходящий исход.
  Описать причину по журналу и предложить правку реплея владельцу. Применять — только после
  согласования.
- Код игры (`src/`) не менять. Если без этого не обойтись — описать в отчёте и согласовать.

## Результат

- `scripts/run_feedback_regression.ps1`, `scripts/run_multiplayer_regression.ps1`,
  `scripts/run_services_regression.ps1`, `scripts/run_shop_regression.ps1`;
- при необходимости `smoke.ps1`;
- `tests/replays/regression-steps/`;
- `docs/native-port/reports/T12.md`.

Работать в отдельном git worktree от текущего `master`.

## Критерии приёмки

- [ ] Таблица разброса базового режима по трём прогонам.
- [ ] В режиме по умолчанию три полных прогона четырёх наборов дают **один и тот же** набор
      пройденных и непройденных проверок.
- [ ] `vases_pc_explicit_seed`, `vases_pc_place_seed` и `mouse_player_two_places` либо проходят во
      всех трёх прогонах, либо стабильно не проходят с причиной по журналу и предложением
      владельцу.
- [ ] `pc_settings_back` — отдельно: исход в каждом прогоне, без включения флага T07b.
- [ ] `-WallClock` даёт прежнее поведение runner (сравнение аргументов игры с `master`).
- [ ] `.\build.bat test` проходит; ожидания `check_*` не изменены (diff пуст).

## Вне рамок

Включение `pvz_gamepad_repeat_fix` по умолчанию; изменение ожиданий проверок; детерминизм
обычной игры вне реплеев.
