# pvz-console-edition: технические заметки

Сад дзен, магазин и альманах поддерживают мышь: инструменты и перенос
растений, покупки с подтверждением, листание товаров и выбор описаний.
Управление и границы проверки: [docs/services-mouse.md](services-mouse.md).

На экране мини-игр мышь поддерживает наведение с анимацией, нажатие и
запуск по ЛКМ, отмену при отпускании вне строки и прокрутку колёсиком.
Для импортированного тестового сохранения используйте `Start-Minigames.bat`.
Инструкции: `docs/minigames-save.md`; проверки:
`docs/testing-minigames-2026-10-07.md`.

В **Heavy Weapon** мышь одновременно ведёт карету по горизонтали и
направляет башню к курсору. Карета догоняет курсор с игровой скоростью,
для стрельбы удерживайте ЛКМ на поле. Клик по карточке сразу покупает
усиление и не включает огонь, даже при перетаскивании на поле.
Эта схема действует в обоих режимах мыши;
при вводе с геймпада возвращается штатное управление двумя стиками.

Рабочий прототип статической рекомпиляции Xbox 360 / XBLA Plants vs. Zombies с RexGlue 0.10.0. Основная задача проекта — управление мышью на ПК.

Поддерживается конкретный `default.xex`: TitleID `584109FF`, MediaID `528550BC`, версия `0.0.1.4`. Хеши закреплены в `config/game.lock.json`: смещения хуков относятся только к этой сборке.

## Запуск

Собранный исполняемый файл: `build/pvz-console-edition.exe`. Из PowerShell в папке проекта:

```powershell
.\run.ps1 -Mouse
```

Доступны две логики курсора:

| Режим | Поведение на поле Adventure |
|---|---|
| **PC** (по умолчанию) | Курсор следует мыши; сначала выбирается карточка, затем клетка. Солнце собирается кликом. После посадки выбор снимается, ПКМ отменяет его. |
| **Console** | Курсор притягивается к центру клетки исходной логикой игры. Текущая карточка остаётся выбранной для повторной посадки; близкое солнце и монеты собираются автоматически. Колесо меняет карточку, ПКМ выкапывает растение. |

```powershell
.\run.ps1 -CursorMode PC
.\run.ps1 -CursorMode Console
```

`-CursorMode` сам включает управление мышью. Во время игры режим можно сменить в **F4 → PvZ → pvz_cursor_mode** (`pc` / `console`). Для сохранения выбора используется Save в настройках RexGlue либо строка `pvz_cursor_mode = "console"` в `runtime-data/user/pvz.toml`. Переключение сбрасывает выбор ПК-карточки и захваченные кнопки. В **PC** кнопки меню и диалогов подсвечиваются только под мышью; уход на фон, за боковые границы или потеря фокуса снимает подсветку. В **Console** выбранная кнопка сохраняет консольную подсветку после ухода мыши.

В самой игре откройте **Options → PC Settings → Mouse: PC / Console**: каждый клик меняет логику и сразу сохраняет выбор в `runtime-data/user/pvz.toml`. Здесь также доступны VSync, пауза при потере фокуса, режим дисплея, пропуск заставки и язык. Навигация геймпадом включает новые пункты. Для абсолютного управления запускайте игру с `-Mouse`.

### Язык игры

Игра читает язык один раз при запуске: XConfig `USER_LANGUAGE` (категория 3, настройка 9) через `ExGetXConfigSetting` в `826163F0`, результат хранится в LawnApp `+804` (регион — в `+808`, `826161F0`). Загрузчик ресурсов `8219F528` по этому полю подключает `en/jp/de/fr/es/it.pak`: 1 — английский (при регионе США/Канада вместо него `na.pak`), 2 — японский, 3 — немецкий, 4 — французский, 5 — испанский, 6 — итальянский. Все шесть пакетов есть в XBLA-пакете и на диске, импорт их копирует.

В ReXGlue это значение — cvar `user_language`. Порт выставляет его из `pvz_language` (`en`, `de`, `es`, `fr`, `it`, `jp`) в `OnLoadXexImage`, до загрузки XEX: SDK тоже читает `user_language` при загрузке модуля, для названий достижений. Если пакета выбранного языка нет в данных игры, запуск идёт на английском (предупреждение в журнале). Строка **Language** на странице PC Settings перебирает доступные языки и сохраняет `pvz_language`; пока выбор отличается от текущего, она показывает «Next launch: …». Язык запуска возвращает `pvz::RunningLanguage()`.

Строки порта переводятся на язык запуска. `pc_locale.h` задаёт `Localized` — один текст на шести языках; пустой перевод означает английский или, для замен в `pc_text.h`, собственный текст игры. Где у игры есть подходящая строка, порт берёт её: хук загрузчика строк `82284848` разбирает LawnStrings текущего языка в таблицу, а `pvz::PortText(text, key)` возвращает свой перевод, иначе строку игры по ключу (`BACK`, `SHOP_BUTTON`, `START_ONSLAUGHT`, `INBOX`, `LETS_ROCK_BUTTON`, `QUIT_MESSAGE`, `UNLOCK_FULL_VERSION`, `ACHIEVEMENTS`…), иначе английский. Свой перевод задан там, где строка игры не подходит по смыслу или ширине: испанский `MENU_BUTTON` — «Menú principal», шире кнопки Menu. В `HELP_TEXT_5_1` других языков порт не заменяет текст, а отрезает от текста игры предложение про дома друзей с `<l>`.

Замены фраз (`MousePrompt`, `2P_JOIN_TEXT`) опираются на формулировки LawnStrings каждого языка: «Drücke <A>», «Pulsa <A>», «Appuyez sur <A>», «Premi <A>», «<A>を押して». Значок, оставшийся без фразы, становится названием кнопки мыши («Linksklick», «clic droit», «左クリック»). Неизвестная фраза безопасна: остаётся только эта замена значка.

Шрифты игры ограничивают набор символов. В немецком, испанском, французском и итальянском пакетах шрифты содержат Latin-1 без типографских кавычек, многоточия и (кроме одного французского шрифта) «ёлочек», поэтому переводы пишутся прямыми апострофами и `...`. Японские шрифты содержат около тысячи кандзи — только те, что нужны самой игре; каждый японский перевод проверен по общему набору символов всех двенадцати шрифтов `jp.pak`. Длинные японские фразы для Дерева мудрости разбиты вручную, как в самой игре: перенос по словам там не работает. Названия языков в строке Language — самоназвания (Deutsch, Español…), кроме тех, что шрифт текущего языка не нарисует (японский шрифт: スペイン語, フランス語; латинские: Japanisch и т. п.). ImGui-меню (достижения, читы) рисуются шрифтом SDK: Latin-1 и японский из `msgothic.ttc`.

### Разрешение рендера

Игра рисует кадр 1280×720. ReXGlue умеет рендерить его только в целое число раз крупнее (`resolution_scale`, 1–7, у D3D12 предел зависит от устройства): эмуляция EDRAM, resolve и адресация текстур работают в целых пикселях гостя, поэтому дробный масштаб (1,5× для 1080p) невозможен без переделки SDK. Вместо этого `pvz_render_scale = "auto"` (по умолчанию) рендерит не меньше высоты экрана и только уменьшает картинку презентером: 768 строк — 1×, 900–1440 — 2×, до 2160 — 3×, выше — 4×. Высота берётся из текущего режима монитора (`EnumDisplaySettings`, физические пиксели при любом DPI; монитор — по cvar `monitor`), а для `pvz_display_mode = "fullscreen"`, который переключает монитор в `window_height`, — из него. Значения `1`–`4` задают масштаб явно.

`resolution_scale` регистрирует GPU-плагин xenos, который загружается после `OnPreSetup`, поэтому масштаб выставляется в `OnFinalizePaths`: плагин уже загружен, а GPU создаётся сразу после. Строка **Resolution** на странице PC Settings перебирает Auto, 1×–4×; текущий Auto показан как «Auto (2x)», выбор до перезапуска — с пометкой «(restart)». Скриншоты F12 и `--pvz_capture_frame` сохраняют кадр в разрешении рендера. `smoke.ps1` по умолчанию передаёт `--pvz_render_scale=1`: регрессии меряют кадры 1280×720.

### Клавиатура

Клавиатура не превращается в кнопки геймпада: `BridgeMnkDriver` передаёт в SDK только клавишу паузы, а остальное разбирает `key_bindings.cpp`. Действия и cvar'ы: пауза — `keybind_start` (SDK, `Escape`; драйвер MnK превращает его в Start игрока на мыши), скриншот — `pvz_key_screenshot` (`F12`), лопата — `pvz_key_shovel` (`X`), карточки 1–10 — `pvz_key_seed1`…`pvz_key_seed10` (`1`…`9`, `0`). Имена клавиш — как в `keybind_*` SDK (`rex::ui::ParseVirtualKey`). Автоповтор зажатой клавиши отбрасывается, иначе карточка переключалась бы туда-обратно.

Карточки и лопата уходят в очередь событий мыши (`MouseEventKind::Key`) и действуют в точке указателя, как клик: в PC клавиша берёт карточку или лопату (`PcPacketClick`, `PcToggleShovel`) или возвращает её, следующий клик сажает или копает; дорогая или перезаряжающаяся карточка даёт штатный звук отказа. В Console цифра выбирает карточку (`GamepadControls +BC`), `X` удерживается как ПКМ и копает в клетке курсора. В мини-играх с покупками (Beghouled, Zombiquarium) цифра покупает, в Slot Machine и Heavy Weapon клавиши карточек не действуют, в Versus лопаты нет. Без указателя в окне клавиши ждут мышь; пока открыто окно Cheats или Keyboard, нажатия в игру не идут.

Окно **Keyboard** (строка в PC Settings, ImGui) показывает все действия: клик по клавише ждёт новую (захват идёт в драйвере, клавиша никуда больше не попадает), повторный клик оставляет старую, **Clear** снимает привязку, **Reset to defaults** возвращает исходные. Клавиша, уже занятая другим действием, переходит к новому. `F3`, `F4`, `F7` и `` ` `` заняты оверлеями SDK и не назначаются. Реплеи нажимают клавиши действиями `key_down`/`key_up` (x — виртуальный код Windows): `tests/replays/keyboard_seeds.csv` берёт и возвращает подсолнух цифрой, сажает его, выкапывает лопатой с `X`, проверяет отказ дорогой карточки и выбор/удержание лопаты в Console.

Проверено 16.10.2026 на всех шести языках: `smoke.ps1 --pvz_language=<code> --pvz_mouse_cursor=true --pvz_test_unlock=true` с реплеями `game_settings.csv` и `oct7_chooser.csv` и уровнем 1-1 (`fixture_level 1`), кадры `--pvz_capture_frame`. Титульный экран («Zum Starten klicken!»), Help & Options со страницей PC Settings (все строки помещаются в кнопки, «Al riavvio: Giapponese» после смены языка), выбор растений (MENÜ, LOS GEHT'S!, メニュー) и уровень (Menú, «¡Haz clic en la hierba…», «芝生をクリックして…») без английского; аварий нет. `check_game_settings.py` на английском прогоне — 9/9. Не проверены на кадрах: диалоги разблокировки, Bonus Games, почта, титры и ImGui-меню. Окно импорта при первом запуске и редкие ошибки проверки пакета остаются английскими.

Игровых файлов в сборке нет. При первом запуске без `assets/default.xex` игра показывает окно **Game Files**: игрок выбирает свой XBLA-пакет (LIVE/PIRS, TitleID 584109FF), игра проверяет SHA-1 блоков и SHA256 `default.xex`, `main.pak`, `en.pak`, копирует файлы в `assets` и спрашивает, купленная ли это полная версия (пакет у триала и полной версии один). Ответ записывается в `.pvz-import.toml` и выбирает Trial или Full; это подтверждение владельца, а не проверка лицензии Xbox.

В Trial подсолнух **$** и все «Get Full Game» разблокируют полную версию после подтверждения покупки (**I Bought It**) — штатным переходом trial → full без перезапуска. В Full **$** открывает магазин Crazy Dave. `Import-Game.ps1` остаётся запасным путём. Образы дисков (.iso) пока не поддерживаются. Подробности: [docs/distribution.md](distribution.md).

```powershell
.\Import-Game.ps1 -Package 'C:\Games\PvZ\584109FF\000D0000\container' -Edition Full
```

Настройки и сохранения продолжают использовать `pvz.toml` и прежние каталоги профиля. Версия продукта: **0.1.0**; имя EXE: `pvz-console-edition.exe`. Иконка взята из Xbox-миниатюры игры; она встроена в EXE вместе с метаданными Windows.

`-Mouse` включает экспериментальный абсолютный курсор и клики. **Escape** — Start / пауза. Клавиатура и геймпад нужны как запасной способ пройти ещё не адаптированные экраны. Без `-Mouse` сохраняются стандартные назначения LMB → A, RMB → B.

При управлении мышью консольные полосы подсказок и приглашение второго игрока нажать Start скрываются. Нажатие кнопки, движение стика или триггера физического контроллера первого игрока возвращает подсказки и штатное управление; новое движение или клик мыши возвращает выбранную логику **PC/Console**. Неподвижная мышь, удержание кнопки и небольшой дрейф стика не переключают режим. Автопереключение можно отключить через **F4 → PvZ → pvz_input_auto_switch**. Эта настройка не меняет предпочтение `pvz_cursor_mode`. Клавиатура в игре отключена, кроме Escape (Start: пауза и назад); тексты подсказок описывают действия мышью.

На экране **Press A to Start** можно нажать ЛКМ. Подсолнух **Options** в главном меню и кнопка **Back** в его диалоге работают с мышью; диалоги можно перетаскивать за фон.

Область Adventure автоматически выбирает видимую кнопку: **START ADVENTURE** на новом профиле или **ADVENTURE** с номером уровня при наличии прогресса. Это применяется к наведению, клику и восстановлению фокуса при переключении на контроллер.

Кнопки панелей **MORE WAYS TO PLAY** и **EXTRAS**, включая **Back**, принимают клики. Наведение воспроизводит штатный звук BLEEP один раз при входе на кнопку; звук работает в PC и Console. Скрытые игрой кнопки не активируются. В trial режимы More Ways открывают исходное окно **Locked!** с **Maybe Later**; в полной версии для ещё не открытых режимов показывается требование пройти Adventure и кнопка **OK**.

В режиме **PC**, одиночный **Adventure**: ЛКМ по готовой карточке выбирает растение с исходной анимацией увеличения, следующий ЛКМ по клетке сажает; ПКМ отменяет выбор. После посадки карточку нужно выбрать снова; пустая рука не оставляет карточку постоянно подсвеченной. Проверки цены, перезарядки и допустимой клетки выполняет исходный код игры в обоих режимах. Солнце, обычные монеты и наградная карточка нового растения собираются ЛКМ; их автоматический сбор при приближении геймпадного курсора отключён только в PC. Остальные типы наград сохраняют исходное поведение. В обычном тексте обучения A/B заменяются на мышь, Start — на Escape; при контроллере возвращается оригинальный текст.

Пользовательские настройки: `runtime-data/user/pvz.toml`; журналы: `logs/run-*.log`. Настройки создаются при первом запуске из `config/pc_defaults.toml`. Изменения файла defaults не перезаписывают существующий пользовательский конфиг.

## Сборка

Для запуска Windows-сборки нужны x64-процессор с SSE4.1 и видеокарта с драйвером Direct3D 12, Feature Level 11_0 или выше. Это граница совместимости по коду; минимальные модели CPU/GPU для стабильных 60 FPS ещё не измерены. Подробности: [требования и фризы](startup-performance-2026-10-11.md).

Для сборки дополнительно нужны Python 3.10+, Visual Studio с C++ SDK, Clang/LLVM и CMake/Ninja. Здесь проверены VS 2026 Community и Clang 20.1.8.

```powershell
.\setup.ps1 -Build
.\build.bat test
```

`setup.ps1` скачивает закреплённый Windows SDK, проверяет SHA256, извлекает уже находящийся в проекте XBLA-контейнер и генерирует C++. При другом расположении контейнера:

```powershell
.\setup.ps1 -Build -Package 'C:\Games\PvZ\584109FF\000D0000\container'
```

Повторная сборка: `.\build.bat`. Код игры и ресурсы берутся из предоставленного контейнера; `assets/`, `generated/default/`, SDK, локальные исследования, логи и оригинальные контейнеры исключены из Git. `cmake/rexglue.cmake` сохранён в проекте, чтобы сборка не зависела от повторного `rexglue init`.

## Проверенное состояние

Систематический аудит ввода 8 октября: 58 классов Xbox Widget, 4 Controls и
224 именованных обработчика Android TV как справочник. Новые маршруты и
перечень оставшихся ручных проверок: [docs/input-coverage.md](input-coverage.md).
Точные Xbox-адреса: [research/input-coverage/handlers.md](research/input-coverage/handlers.md).
Количество классифицированных обработчиков не означает полного прохождения
или проверки каждого экрана. Повторить нативные сценарии: `scripts/run_input_audit.ps1`,
затем `python scripts/check_input_coverage.py`.

- C++ генерируется без `--force`, приложение собирается.
- D3D12 и аудиосистема инициализируются. Получены кадры заставки PopCap и главного меню PvZ, 1280×720.
- Запуски длительностью до 180 секунд прошли без fatal; автоматическая проверка завершает только запущенный ею процесс.
- Тест координат мыши проверяет DPI, полосы по краям, границы, отдельное смещение поля и недопустимые значения.
- Найден и вызван реальный `WidgetManager` игры, размер 800×600; мышь передаётся из UI в игровой поток.
- Подтверждены старт по клику, Options/Back, переход в Adventure, выбор первой карточки, отмена ПКМ, посадка и стрельба горохострела. Попытка выбрать карточку во время перезарядки отклоняется.
- Режим Console проверен 125-секундным реплеем: штатное притягивание, посадка без выбора карточки перед каждым кликом, автоматический сбор солнца. ## Доработки по тестированию, 2026-10-06

Options → **PC Settings**: переключение Mouse PC/Console, VSync,
пропуск интро, пауза при потере фокуса и Windowed / Fullscreen / Borderless.
С VSync кадры идут в темпе монитора, но не чаще 100 FPS; без VSync — 60 FPS.
Fullscreen выбирает самую высокую доступную частоту до 100 Гц.
ЛКМ по PopCap пропускает ролик даже при выключенном автоматическом пропуске. Изменения
сохраняются отдельно в `runtime-data/user/pvz.toml`. Escape заменяет Enter
как Start/паузу; старый стандартный Enter мигрирует автоматически.

- Дэйв продолжает диалог по ЛКМ, консольная подсказка продолжения скрыта.
- В PC лопата берётся ЛКМ, рисуется вместо системного указателя,
  подсвечивает растение и выкапывает его одним ЛКМ. ПКМ отменяет инструмент.
- В Console удержание ПКМ до заполнения индикатора и отпускание выкапывает растение; колесо переключает карточки вместо LB/RB. Стрелка и тень следуют за мышью независимо от выбранной клетки.
- В PC скрыты рамка и тень консольного курсора; лента оставляет пустую руку
  после использования карточки. Выбор сопровождается SOUND_SEEDLIFT,
  недоступная/перезаряжающаяся карточка — SOUND_BUZZER.
- Выбор набора поддерживает добавление и возврат карточек с исходной анимацией;
  кнопка **LET'S ROCK!** запускает уровень. NEXT LEVEL реагирует на мышь.
- При активности настоящего геймпада указатель ОС скрывается, подсказки
  возвращаются. Change Storage скрыт в исходном диалоге настроек.
- PS3-глифы и иконки переключаются автоматически для основного Sony-контроллера
  через SDL. Для XInput-обёрток предусмотрено `pvz_controller_glyphs = "playstation"`;
  принудительный Xbox — `"xbox"`, стандартное значение — `"auto"`.

PS3-ресурсы находятся в `assets/pc/dualshock`; их происхождение и SHA-256
записаны в `sources.json`. Воспроизводимое извлечение:

```powershell
python scripts/extract_ps3_controller_assets.py 'PS3 Image/PS3_GAME/USRDIR/NPUA-30059/USRDIR/data/main.pak'
```

Физический DualShock, подавление указателя ОС и синхронизацию монитора нужно
проверить на оборудовании тестера. Fullscreen меняет режим текущего монитора
на `window_width` × `window_height`; Borderless сохраняет разрешение рабочего
стола. При недоступном режиме Fullscreen использует полноэкранное окно.

VSync запрещает DXGI tearing; игра ждёт VBlank монитора с окном, поэтому
75 Гц дают 75 FPS, 100 Гц — 100 FPS, а 144/165 Гц — каждое второе обновление.
Скорость игры от этого не зависит: логика идёт шагами по 10 мс. Без VSync
кадры ограничивает таймер `pvz_frame_limit` (60 FPS). Изменение VSync
пересоздаёт swap chain через API SDK. VRR не проверялся.
Результаты текущих прогонов: [отчёт от 7 октября](testing-2026-10-07.md).

Реплеи: `level_5_mouse.csv`, `level_8_mouse.csv`, `level_10_mouse.csv`,
`award_mouse.csv`, `game_settings.csv`. `fixture_level` и `fixture_award`
доступны только при включённом диагностическом реплее; тесты должны запускаться
на отдельном профиле smoke. Пауза при потере фокуса не возобновляет игру
автоматически при возвращении в окно.

## Диагностика

Адаптация выбора растений и мини-игр: [управление и проверенные сценарии](minigames-mouse.md).

```powershell
.\smoke.ps1 -Seconds 30 --pvz_mouse_cursor=true --pvz_input_trace=true --keybind_a=Space --keybind_b=Backspace
```

Отчёт: `runtime-data/smoke-latest.json`. Он проверяет инициализацию GPU и отсутствие раннего падения, а не работоспособность игрового процесса.

Снимок игрового framebuffer, без захвата рабочего стола:

```powershell
.\run.ps1 -Mouse --pvz_capture_frame=F:/src/PVZXboxRecomp/.cache/frame.ppm --pvz_capture_delay=30
python scripts/ppm_to_png.py .cache/frame.ppm .cache/frame.png
```

Для последовательности кадров доступны `--pvz_capture_count=14 --pvz_capture_interval=6`: снимки получают суффиксы `-1`, `-2` и далее. По умолчанию сохраняется один кадр.

Для воспроизводимой проверки событий есть `--pvz_input_replay=<absolute-path.csv>`. Строки: `seconds,x,y,action`, координаты нормализованного экрана 800×600; действия `move`, `left_down`, `left_up`, `right_down`, `right_up`, `cancel`. Поле рисуется по центру гостевого кадра 1280×720: перед передачей в WidgetManager/Board выполняется отдельный пересчёт. Реплей проходит через ту же очередь, что мышь, но не проверяет физический ввод ОС. На время режима реплея физические события мыши игнорируются. Его часы отсчитываются от запуска модуля, поэтому нужно оставить время на загрузку.

Действия `wait_title`, `wait_menu` и `wait_board` ожидают готовность соответствующего экрана до 90 секунд, приостанавливая часы реплея. Пример со свежим профилем: `tests/replays/adventure_mouse.csv` — Options/Back/Adventure, отмена, одна посадка и отклонение карточки во время перезарядки. Запуск из этой папки:

```powershell
.\smoke.ps1 -Seconds 180 --pvz_mouse_cursor=true --pvz_input_trace=true --keybind_a=Space --keybind_b=Backspace --pvz_input_replay=F:/src/PVZXboxRecomp/tests/replays/adventure_mouse.csv
```

`mode_pc` и `mode_console` меняют настройку во время реплея. `tests/replays/cursor_modes.csv` проверяет обычную посадку PC, переход в Console, притягивание, автосбор и возврат в PC без выбранной карточки. Координаты в строках смены режима не перемещают мышь.

`tests/replays/menu_hover.csv` проверяет подсветку Adventure и Options, уход на фон и в обе стороны за область интерфейса, наведение/уход с Back в диалоге, сброс указателя и различие PC/Console.

`tests/replays/adventure_entry.csv` проверяет вход в Adventure, клики по фону, отмену клика при отпускании вне кнопки и переключение владения вводом. Реплей подходит для свежего профиля и копии профиля с прогрессом; пользовательский профиль для автоматических прогонов следует копировать в отдельный `UserDataRoot`.

`tests/replays/input_ownership.csv` проверяет мышь → контроллер → мышь в меню и Adventure, неподвижную мышь, дрейф, выбор/отмену, посадку и переключение PC/Console. Действия `pad_press`, `pad_neutral`, `pad_drift` подают образцы в детектор активности, **не** эмулируют игровые кнопки и подключённое устройство. Это проверка переключения и отображения; физический геймпад нужно проверить отдельно. Подходящий запуск: `smoke.ps1 -Seconds 115 --pvz_mouse_cursor=true --pvz_input_trace=true --pvz_input_replay=F:/src/PVZXboxRecomp/tests/replays/input_ownership.csv`.

`tests/replays/menu_panels.csv` проверяет повторный вход на кнопку, обе боковые панели и Mail; подходит для `--pvz_cursor_mode=pc` и `console`. `tests/replays/menu_panels_actions.csv` рассчитан на свежий профиль пробной версии: клики по пяти режимам, закрытие Locked через Maybe Later, Options/Back и переключение логики курсора. Для прежних сценариев trial используйте `--pvz_full_version=false`. Для обоих сценариев достаточно `smoke.ps1 -Seconds 95` с `--pvz_mouse_cursor=true --pvz_input_trace=true --pvz_input_replay=<absolute-path.csv>`.

`tests/replays/game_settings.csv` проверяет страницу PC Settings: режим мыши PC → Console → PC, VSync, автопаузу, три режима дисплея, язык (English → German, сохраняется до следующего запуска), возврат и повторный вход на страницу, сохранение отдельных настроек и исходные настройки игры. Запуск: `smoke.ps1 -Seconds 88 --pvz_mouse_cursor=true --pvz_input_trace=true --pvz_input_replay=F:/src/PVZXboxRecomp/tests/replays/game_settings.csv`.

Расширенный сценарий для сбора случайно падающего солнца и награды первого уровня:

```powershell
python scripts/make_sun_replay.py .cache/adventure_sun.csv
.\smoke.ps1 -Seconds 180 --pvz_mouse_cursor=true --pvz_input_trace=true --keybind_a=F13 --keybind_b=F14 --keybind_start=F15 --pvz_input_replay=F:/src/PVZXboxRecomp/.cache/adventure_sun.csv
```

Сценарий перебирает точки поля обычными событиями мыши; из-за случайного появления солнца точное число посадок может различаться. Готовность экрана, выбор/отмена, успешная посадка и принятие монеты видны в журнале. Для коллекции логируется только реальный переход монеты в состояние сбора. Отдельный отчёт последнего ручного анализа реплея: `runtime-data/mouse-replay-latest.json`.

Дополнительный инструмент анализа, не входящий в обычную сборку:

```powershell
.\build.bat --target pvz_inspect
.\build\pvz_inspect.exe assets .cache/pvz-image.bin
```

## Доработки от 6 октября

В режиме мыши текст Дэйва рисуется на 12 игровых пикселей ниже. В Console
стрелка и тень отделены от привязанной к сетке выбранной клетки. Лопата
использует исходный таймер удержания B через ПКМ; короткое нажатие не выкапывает.

Просканированы 1313 строки LawnStrings. `pc_text.h` адаптирует сообщения
о сохранении, профилях и платформе, а также подсказки под мышь и текущие
клавиши. Текст обучения меняется во время рисования, сохраняя вариант
для контроллера при переключении ввода. Отчёт: `docs/text-audit-2026-10-06.json`.
Для повторного аудита запустите игру с `--pvz_asset_audit=true`, затем
`python scripts/audit_game_text.py runtime-data/diagnostics/lawnstrings-native.bin`.

После изменения громкости меню восстанавливает потерянный музыкальный канал
через исходный запуск темы, включая настройки инструментов модуля.
Работающая тема не перезапускается. Аудиопрогоны: `audio_settings_zero.csv`;
`--pvz_audio_trace=true` измеряет энергию выходного PCM. Только в реплее
`--pvz_test_drop_menu_music=true` моделирует потерю канала для проверки восстановления.

Для обычной картинки горохострела используется отрисовка исходных слоёв
анимации вместо повреждавшегося кэшированного изображения. Текстуры игры
не заменяются. Диагностический `--pvz_peashooter_direct_draw=false` возвращает
исходную отрисовку для сравнения.

Нажатия мышью в главном меню теперь используют штатные состояния кнопок,
включая анимацию удержания и отмену при отпускании за пределами кнопки.
Во время игры доступна кнопка Menu. На How to Play и Controls добавлена
Back; эти экраны также закрываются ПКМ. Диалоговые окна можно перемещать
по всей видимой области игры, включая боковые поля.

Клики абсолютной мыши исключены из эмуляции кнопок геймпада. В PC солнце
собирается отдельными кликами, без сбора при удержании ЛКМ. Звук пакета
играет при выборе, без повторного проигрывания при посадке. При выбранной
лопате её лоток пуст; используется исходная отдельная текстура лотка.

Каждый кадр игры выводится один раз с GPU-потока; с VSync такой Present
ждёт VBlank, без VSync разрешён tearing. Пока открыт ImGui-диалог (меню
Achievements/Cheats, уведомление о достижении, оверлеи SDK), SDK рисует
с потока окна на каждом обновлении экрана, а повторные кадры выводятся без
ожидания. Раньше уведомление о достижениях было зарегистрировано всегда,
и в borderless/fullscreen лишние Present отнимали обновления экрана у кадров
игры: рывки исчезали только после сворачивания окна. Тестер подтвердил
исправление.
Замеры: [вывод кадров](frame-pacing-2026-10-14.md).
