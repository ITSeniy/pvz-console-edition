## 3. Как воспроизвести

Из корня проекта, PowerShell:

```powershell
python -I scripts/classify_xbox_functions.py --self-test
python -I scripts/classify_xbox_functions.py
python -I scripts/classify_xbox_functions.py --check --sample
foreach ($reviewOffset in 0,5,10,15) {
    python -I scripts/classify_xbox_functions.py --review-context medium --review-offset $reviewOffset
}
git check-ignore research/function-classes/full-analysis.json research/function-classes/library-zones.json
```

Обычный запуск создаёт оба CSV, оба research JSON и T11.md. `--check`
пересчитывает **все пять выходов**, сравнивает побайтно и ничего не пишет.
Отсутствующий/изменённый research-файл — ошибка; после удаления research
сначала нужен обычный запуск. T11b.md — ручной отчёт, не выход генератора.

`--review-context` читает полный JSON, печатает SHA входов и показывает
реальные инструкции через локальный Capstone. Это просмотр, не
автоматическая оценка собственного предсказания. Полное тело:
`python -I scripts/classify_xbox_functions.py --inspect 82191970`.

Пересчёт чисел и получение отдельного списка unassigned без новых файлов:

```powershell
@'
import collections, hashlib, json
from pathlib import Path
p = Path('research/function-classes/full-analysis.json')
d = json.loads(p.read_text(encoding='utf-8'))
rows = d['functions']
print('full_analysis_sha256', hashlib.sha256(p.read_bytes()).hexdigest())
print('input_manifest_sha256', d['input_manifest_sha256'])
print('levels', dict(collections.Counter(r['class_confidence'] for r in rows)))
print('signatures', dict(collections.Counter(r['class_confidence'] for r in rows
    if r['evidence_kind'] == 'unique-field-signature')))
for area in ('game', 'sexy', 'middleware'):
    rs = [r for r in rows if r['region'] == area]
    total = sum(r['bytes'] for r in rs)
    covered = sum(r['bytes'] for r in rs if r['class'] not in ('unknown', '<global>')
        and r['class_confidence'] in ('high', 'medium'))
    print(area, len(rs), total, covered, 100 * covered / total)
print('unassigned: address,region,bytes')
for r in rows:
    if r['assignment'] == 'unassigned':
        print(r['address'], r['region'], r['bytes'], sep=',')
'@ | python -I -
```

## 4. Результаты

### Библиотеки — подтверждено косвенно по Xbox

**660 функций / 171 928 байт** перенесены из sexy в middleware.
Выделены 292 непересекающиеся зоны; все границы пересоздаются и перечислены
в T11.md и research. Адресные промежутки не заполняются только по соседству.

| Метка семейства | Функций |
| --- | ---: |
| libpng | 402 |
| JPEG | 122 |
| JPEG-2000 | 110 |
| Общие libpng/zlib-помощники | 23 |
| Отдельно подтверждённые zlib-входы/помощники | 3 |

Метка семейства — происхождение замыкания, не обещание точного исходного
модуля каждого helper. В libpng-замыкании встречаются zlib и общие
C-помощники; здесь устанавливается домен middleware.

- Корни: 24 принятых `png_*` имени, 26 функций с диагностическими строками,
  JPEG-таблица сообщений, 72 функции с JPEG error-протоколом и один
  отдельно подтверждённый versioned zlib-init.
- Примеры строк: `8256ACCC → 827D39C0` (`libpng error`),
  `8257486C → 827D435C` (текст о read_data_fn/write_data_fn).
- JPEG-таблица `8207AEA8` содержит сообщения о версии/структуре JPEG.
  Ошибки часто выбираются числом. Связанный Xbox-протокол: err через
  `[this+0]`, msg_code по `err+14`, обработка error callback. Это не
  назначение C++-класса по смещениям: запись в такой объект несовместима
  с неизменяемой C++ vtable. Принятые классы/RTTI остаются барьерами.
- zlib: `8256CD30 li r5,0x38`, строка `1.1.3` по `827D3A8C`,
  `8256CD40 bl 82594410`. Сам caller — libpng; **callee** `82594410`
  выделен как zlib-root. Независимые строки: `deflate 1.1.3` по
  `82082CA0` и `inflate 1.1.3` по `82084710`.
- JPEG-2000: ISO/IEC 15444 в строках `827D5BD8`/`827D5C14`, функция
  `825922E0`, её literal callbacks и достижимые helpers.
- Замыкание: достижимые прямые calls, literal callback и короткие
  readonly-таблицы. Обратно разрешены только callers, передающие неизменный
  исходный r3 библиотечной функции; поля и произвольные callers такого
  разрешения не дают. Принятые члены классов/RTTI не захватываются.

Все четыре прежние ошибки теперь **middleware, class unknown**:

| Адрес | Доказательство |
| --- | --- |
| 82574820 | libpng-строки о read_data_fn/write_data_fn |
| 82598098 | JPEG: `825980C8` err-load, `825980D4` msg_code=41 |
| 82598310 | JPEG: `825983A0` err-load, `825983B0` msg_code=26 |
| 825985D0 | JPEG: unchanged-r3 call в `825985E4` к предыдущему |

В библиотечном домене **0 сигнатурных назначений и 0 пакетов**. Он исключён
из обучения сигнатур и распространения новых классов. Сохранены 24 прежних
имени свободных png-функций с `<global>`.

### Сигнатуры и уверенность — подтверждено косвенно

Сигнатура требует минимум двух разных смещений, совпадения ширины доступа
и одного класса в замороженном корпусе. Первоначально это **low**.
Medium появляется только при отдельном H/M caller с разрешённым r3 того
же класса; `signature_support` сохраняет конкретный call site и T04 path.
Low-caller не подтверждает medium, low-цикл не подтверждает сам себя.
Все зависимые low/medium пересчитываются с нуля до неподвижной точки.

Это консервативнее приблизительной оценки проверяющего: low-caller или
caller, сам понизившийся после пересчёта, не считается доказанным типом.
Поэтому game ниже ожидавшихся приблизительно 27,4%. Порог и seed ради
увеличения охвата не менялись.

### Формат и пакеты

CSV: `address,region,bytes,class,class_confidence,evidence_kind,key_instruction,batch`.
`key_instruction` — одна настоящая PPC-инструкция; для RTTI-якоря это
точка входа, полная vtable/COL/slot-цепочка находится в JSON. Ключ соединения
с полной записью — address. Манифест и входные SHA — в research и T11.md.

Полный JSON содержит evidence, geographic_region, библиотечный путь,
callers, T04-поля, PC-файлы, хуки, assignment и semantic_area. unassigned —
отдельный фильтр `functions[].assignment`; команда выше печатает список
с областями и размерами. Библиотеки имеют out-of-scope.

Порядок пакетов: риск, доля листовых, хуки T03, PC-аналог, имя.
Calls — справка. Пересечений, unknown, `<global>` и выделенных библиотек
нет. Наличие low не делает пакет готовым к переносу: T10 отдельно
проверяет ABI/чистоту/поведение каждой функции.

## 6. Не проверено и риски

- Статическое замыкание не доказывает полноту всех библиотек. Изолированные
  функции без корней, calls и восстановленных callback могут остаться
  unknown; medium по одному совпадению полей они не получают.
- Семейство общего C-helper неоднозначно. Здесь установлен домен middleware,
  а не исходный модуль каждого helper.
- Medium не доказывает имя невиртуального метода/ABI; возможен общий helper
  или базовая реализация. Это уровень косвенного подтверждения.
- Не восстановлены stack spills, виртуальные цели, jump tables и типы
  возвращаемых объектов. Android/PC не использовался для назначения класса;
  новых имён не выдано, GPL/LGPL-код не копировался.
- Игра, C++-сборка и реплеи не запускались: поведение игры не менялось.
  Проверены анализатор, известные ошибочные адреса и воспроизводимость.
