# Мышь на экране мини-игр — 7 октября 2026

В локальной сборке работают наведение с исходной анимацией выдвижения
строки, удержание ЛКМ с исходным сдвигом нажатой строки, запуск при
отпускании над той же строкой и отмена при отпускании вне неё.
Вне строк постоянное выделение скрыто. Колесо плавно прокручивает список
по одному пункту, останавливаясь на первой и последней странице.
ПКМ возвращает главное меню. Закрытые пункты используют штатную реакцию
игры; прогресс не подменяется.

Области взаимодействия получены из отрисованных строк и области отсечения
списка. Анимация выдвижения и сдвиг нажатия не выталкивают неподвижный
курсор из области клика. Нативное выделение остаётся на видимой странице
при прокрутке, чтобы переключение на геймпад возвращало видимый фокус.
Состояние захвата очищается при смене ввода и удалении экрана.
