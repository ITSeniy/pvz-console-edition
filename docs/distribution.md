# pvz-console-edition: импорт и редакции

Продукт, EXE и новые архивы называются `pvz-console-edition`.
Версия Windows ProductVersion/FileVersion — 0.1.0, FileDescription —
Plants vs. Zombies Console Edition. ICO содержит размеры 16, 24, 32, 48 и
64 пикселя; источник — исходная Xbox-миниатюра `game.png`.
Иконка встроена в ресурсы Windows и применяется к игровому окну.

Внутреннее имя сгенерированного кода `pvz`, имя пользовательского
конфига `pvz.toml`, TitleID и каталоги сохранений сохранены для совместимости.
Папка рабочего проекта пока остаётся на прежнем пути.

## Условие Full

По умолчанию используется Trial (`license_mask=0`). Full (`license_mask=1`)
включается после успешного импорта поддерживаемого контейнера LIVE/PIRS
и явного подтверждения владельца, что это его купленная полная Xbox-копия.
Это локальная декларация владельца, не проверка Xbox Live и не DRM.
В XBLA бит лицензии сообщается отдельно от содержимого:
[XamContentGetLicenseMask в Xenia](https://github.com/xenia-project/xenia/blob/master/src/xenia/kernel/xam/xam_content.cc).
Само наличие `default.xex` не считается доказательством покупки.

```powershell
.\Import-Game.ps1 -Package 'C:\Games\PvZ\584109FF\000D0000\container' -Edition Full
```

Для Full нужно ответить `YES` на вопрос о владении. Trial можно импортировать
без подтверждения: замените `Full` на `Trial`. Требуется Python 3.10+ только
для импорта; контейнер не изменяется. Другие версии игры отвергаются.

Импорт сначала извлекает контейнер во временную папку, проверяет SHA1
каждого блока, TitleID и закреплённые SHA256 `default.xex`, `main.pak`,
`en.pak`. Другие существующие файлы не перезаписываются, если отличаются.
После проверки файлы переносятся в `assets`, затем атомарно записывается
`assets/.pvz-import.toml`. Там находятся хеши и декларация, без аккаунта Xbox
и исходного пути контейнера. При следующем запуске EXE заново хеширует три
основных файла. Отсутствующая декларация, изменённые файлы, неверный TitleID
или повреждённый документ оставляют Trial; причина записывается в журнал.
Настройки `pvz_full_version` и `license_mask` не заменяют импорт.
Для внутренних тестовых сохранений доступен явный флаг
`--pvz_test_unlock=true`: он сообщает игре Full без декларации импорта.
По умолчанию он выключен; `Start-Minigames.bat` включает его для тестового
профиля. Флаг не редактирует сохранение и не снимает ограничения по прогрессу.
Повторный импорт с `-Edition Trial` снимает декларацию Full.

Владелец может редактировать этот локальный файл. Механизм не защищает от
подделки подтверждения покупки и намеренно не выдаёт такую гарантию.
Сохранения не сбрасываются и обычные игровые ограничения по прохождению остаются.

## Подготовка GitHub-архива

```powershell
.\build.bat configure
.\build.bat
.\build.bat test
.\scripts\package_public.ps1
```

Публичный архив формируется по явному списку: EXE, библиотеки, CRT,
Trial-настройки, запуск, импорт, документация, хеши и лицензии библиотек.
В него не попадают игровые PAK/XEX, сохранения, журналы и декларация владельца.
Имя: `pvz-console-edition-0.1.0-win-x64-<дата>.zip`, рядом SHA256.
Упаковщик проверяет метаданные EXE и свежесть сборки. Публикация на GitHub
не выполняется автоматически.

**Это архив программы без игровых данных**, поэтому после скачивания нужен
импорт. Он не является готовой автономной демоверсией. Для такого варианта
потребуется отдельно определить источник и допустимый состав Trial-данных;
текущие локальные ресурсы полной игры публичный упаковщик не добавляет.

Старые тестовые ZIP и sun-fix сохраняют прежние имена и состав.
`scripts/package_test.ps1` предназначен для внутреннего тестирования и
включает игровые данные; для GitHub используется только `package_public.ps1`.
Даже тестовый упаковщик удаляет локальную декларацию Full из своей копии.
