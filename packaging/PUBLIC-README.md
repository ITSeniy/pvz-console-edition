# pvz-console-edition

Windows x64, версия 0.7.0 (бета). Управление мышью; Escape — пауза, ПКМ — отмена.
Запуск: `Start.bat`. Режим мыши меняется в Options → PC Settings.

Архив содержит порт и необходимые библиотеки. Игровых файлов в нём нет:
их даёт ваша собственная Xbox-копия Plants vs. Zombies (Xbox LIVE Arcade,
TitleID 584109FF, версия 0.0.1.4).

## Первый запуск

1. Запустите `Start.bat`. Без игровых файлов откроется окно **Game Files**.
2. Нажмите **Choose game package...** и выберите файл пакета XBLA из папки
   `584109FF\000D0000` вашего хранилища Xbox или образ диска Xbox 360 с
   игрой (`.iso`). Диск сразу открывает полную версию.
3. Игра проверяет пакет (SHA-1 каждого блока и SHA256 `default.xex`,
   `main.pak`, `en.pak`; точные хеши — в `config/game.lock.json`) и
   копирует файлы в `assets`. Это делается один раз.
4. Ответьте, купленная ли это полная версия. Пакет у триала и полной версии
   один и тот же, поэтому редакцию определяет только ваш ответ:
   **Yes, my full version** — Full, **No, play the trial** — Trial.

Ответ «Yes» — ваше заявление о покупке, а не проверка лицензии Xbox Live.

## Полная версия позже

В Trial подсолнух **$** в главном меню (и любое «Get Full Game» в игре)
предлагает разблокировать полную версию: **I Bought It** включает Full сразу,
без перезапуска. В полной версии **$** открывает магазин Crazy Dave.

Без Python можно обойтись. `Import-Game.ps1 -Package <файл> -Edition Trial|Full`
остаётся запасным способом импорта (нужен Python 3.10+).

Подробнее: `docs/distribution.md`. Сохранения: `runtime-data/user`.
