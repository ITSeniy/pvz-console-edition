## 3. Как воспроизвести

PowerShell из корня этого worktree. Нужны существующие `assets`, `generated`,
`.cache`, SDK в `tools`, baseline `runtime-data/zen-shop-probe-user`.
OutputRoot/Tag должны быть новыми. Существующие реплеи не записываются заново.

```powershell
python -I tests/t15_xbox_evidence.py runtime-data/t15-evidence
.\build.bat configure
.\build.bat
.\build.bat test
.\build\b002_synthetic_test.exe runtime-data/t15-b002-synthetic.json
.\build\b003_synthetic_test.exe runtime-data/t15-b003-synthetic.json
pwsh -NoProfile -File scripts/run_native_proof.ps1 -Batch b002+b003 -CompareOnly -OutputRoot runtime-data/t15-final-compare
foreach ($case in @('adventure','versus','minigame','zen','menu')) {
  pwsh -NoProfile -File scripts/run_native_proof.ps1 -Batch b002+b003 -RenderOnly -RenderPartition -Cases $case -OutputRoot "runtime-data/t15-final-render-$case"
}
pwsh -NoProfile -File tests/run_t15_gamepad_proof.ps1 -OutputRoot runtime-data/t15-final-gamepad
python -I tests/t15_repeat_check.py runtime-data/t15-final-gamepad
# Если секундный Co-op не вышел на поле: исходный отказ не удалять.
pwsh -NoProfile -File tests/run_t15_gamepad_proof.ps1 -Cases t07b_coop_hold_matrix -OutputRoot runtime-data/t15-final-coop-repeat
python -I tests/t15_repeat_check.py runtime-data/t15-final-gamepad --coop-repeat runtime-data/t15-final-coop-repeat --output runtime-data/t15-final-gamepad/repeat-proof-accepted.json
foreach ($mode in @('off','on')) {
  foreach ($suite in @('feedback','multiplayer','services','shop')) {
    $tag = "final-$mode-$suite"
    pwsh -NoProfile -File tests/run_t15_regressions.ps1 -Mode $mode -Tag $tag -Suites $suite
    $dispatch = @(Get-Content "runtime-data/t15-regression-$tag-processes.json" -Raw | ConvertFrom-Json)
    while (!(Test-Path (Join-Path $dispatch[0].worker 'runtime-data/receipt.json'))) { Start-Sleep -Seconds 2 }
  }
}
python -I tests/t15_acceptance_audit.py
```

Диспетчеры регрессий асинхронны: проверять `runtime-data/receipt.json` каждого
worker из `t15-regression-<Tag>-processes.json`, а не только код возврата диспетчера.
Локальный `runtime-data/t15-gamepad-run.ps1` сохранён рядом с сырыми доказательствами;
он послужил основой `tests/run_t15_gamepad_proof.ps1`.
он копирует штатный smoke в отдельный worker и запускает четыре неизменённых T07b CSV
с исходным профилем, фиксированными seed/clock и repeat_trace в OFF/ON.
Для дополнительного исследования всех кандидатов доступен `-Discover`.
Обычный полный `-Batch b002+b003` объединяет compare и render в одном запуске;
в этой работе эти фазы запускаются раздельно на одном неизменном EXE.
`-RenderPartition` явно обозначает один графический сценарий; отсутствие Centered
в отдельной части сохраняется как нулевой отрицательный охват. Объединяющий audit
требует все пять сценариев, четыре комбинации и хотя бы одну пойманную инъекцию.
Полный runner без этого ключа по-прежнему отвергает отсутствие отрицательного случая.

## 4. Контракты и достоверность

**Проверено по Xbox:** полный список диапазонов — `bytes` в
`runtime-data/t15-evidence/manifest.json`; в каждой строке CSV находятся вся
дизассемблировка, входные регистры, stores и прямые дочерние вызовы.
Для неименованных функций сохранён Xbox-адрес: Android-имя не объявляется фактом.
PC `SexyAppFramework/WidgetContainer.cpp` использован как ориентир структуры
алгоритма, включая обход siblings; поведение, константы и смещения взяты из Xbox.
GPL/LGPL-код не использовался.

восстанавливается на каждом входе. Seed **42**.

IO или неперечисленные временные stack stores исключают двойное исполнение.

процессах на копиях одного профиля. Frame сохраняет входные SP/LR; дочерним вызовам
