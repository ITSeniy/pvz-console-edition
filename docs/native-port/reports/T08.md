# T08 — граница нативного рендера

## 1. Итог

Подготовлена таблица Xbox-операций, состояния Graphics, загрузки PTX и обходов
в Tod/Reanimation/PoolEffect. Измерены 68 точек на четырёх сценах, по 180 полных
present-интервалов. Вывод — нативный backend возможен с условиями; ABI и полнота
всех косвенных/XDK путей ещё требуют проверки, поэтому результат не объявляется
полностью закрытой границей рендера.

## 2. Изменённые файлы

- `docs/native-port/render-boundary.md` — проектный документ, адреса, доказательства,
  частоты, ограничения, upstream-сопоставление и воспроизводимые команды/помощники.
- `src/render_probe.cpp` — счётчики в одном новом файле, инертном без специальной
  сборки и `--pvz_render_probe`. Ни отрисовка, ни input/state guest не подменяются.
- `docs/native-port/reports/T08.md` — этот отчёт.

Существующие src, CMakeLists, README и scripts/check_* не менялись в T08.
Производные TU/EXE/логи/кадры находятся в research/runtime-data; код внешнего
бэкенда не копировался. Обычный CMake cache восстановлен, обычный EXE пересобран.

## 3. Как воспроизвести

Полные команды — в `render-boundary.md`, включая создание derived TU, CMake cache
injection и восстановление обычной сборки. Текущие доказательства:

```powershell
python -I research/cross-platform/render-boundary/callgraph.py runtime-data/render-boundary/20261017-102807-826/runs.json
python -I research/cross-platform/render-boundary/inspect.py 821da128 82480430 82186540
./build.bat test
git diff --check
```

Первый экспериментальный прогон `20261017-101242-281` имел 65 точек и меньший
caller buffer. Итоговая таблица использует только **68-точечный** повтор
`20261017-102807-826`, без смешивания двух EXE.

Source/bin hashes и caller graph сохранены в static.json, build-inputs.json,
callgraph.json, runs.json и measured.json. Каждый итоговый trace/CSV/log имеет SHA.

его не следует выдавать за отсутствие любых файловых записей в generated.

## 4. Результаты

**Проверено на запуске:** четыре отдельных процесса, каждый записал 180 полных
интервалов, fatal — 0, caller overflow — 0. Всего **720** интервалов,
**884715** entry-вызовов с вложенными счётчиками. Средние/min/max по 68 адресам
и mode/scene — в measured.json, ключевые операции — в документе.

Контактный лист `scenes.png` просмотрен: игровые кадры соответствуют Adventure,
Zombiquarium и Versus. Кадр меню снят позднее измерительного окна и показывает
PC Settings; он подтверждает работоспособность сцены, но не состав первых
180 интервалов MainMenu. Для границ окна авторитетны gate и trace, а не этот кадр.

**Проверено по Xbox-коду и динамически:** Reanimation/Tod matrix обходит
измеренные Graphics entries; `8227C240` дал **27688/22696/6480/75446** вызовов
за окна Menu/Adventure/Zombiquarium/Versus. Непосредственная группа треугольников
`82186540` также имеет прямой D3D path.

**Проверено по Xbox-коду:** PoolEffect `821DA128` использует Graphics triangles,
но в `821DA814..890` меняет состояние устройства напрямую. Назначение всех
bitfields пока неизвестно. В Zombiquarium-окне Pool triangles не наблюдались;
причина известного артефакта этим исследованием не установлена.

**Проверено:** PTX reader `82480430` даёт CPU compressed data до XDK texture
binding. T09 обеспечивает декодирование текущего базового BC3-формата; mutable
MemoryImage, caches и render targets всё равно надо поддержать отдельно.

**Вывод/проектное решение:** перехват полного набора Graphics + Image/DDImage +
Tod matrix/triangles с pool-state adapter выглядит осуществимым. Удалять Xenos
на основании только high-level DrawImage преждевременно. Перечень операций
PvZ-Portable покрывает большую часть семейства, но не доказывает Xbox ABI.

После возврата обычной сборки CTest — **12/12**. Полные gameplay-регрессии T08
не запускались: probe не включён в обычный target, и логика игры не менялась.

## 5. Критерии приёмки

- **Частично:** приведённая проверенная таблица имеет Xbox-адреса и инструкционные
  доказательства, а не только low-имена. Однако полного ABI всех overloads,
  NativeDisplay и всех дополнительных discovery-проб пока нет; неизвестные
  имена/аргументы не объявлены подтверждёнными.
- **Выполнен для измеренной границы:** реальные частоты 68 entry-точек в четырёх
  заданных сценах, 180 интервалов на сцену. Не измерены inline-записи полей и
  входы через `__imp__`, поэтому это не полный GPU/API-профиль всей игры.
- **Выполнен для найденных обходов:** перечислены Tod matrix, triangle-group,
  Pool state и PTX upload, вызывающие адреса и все найденные direct b/bl в
  выбранные backend targets. Исчерпывающий поиск косвенных/XDK обращений не доказан.
- **Выполнен:** вывод «можно с условиями» опирается на таблицу, реальные обходы,
  texture lifecycle и измерения. Готовая реализация backend не заявлена.

## 6. Не проверено и риски

Порядок всех ABI-аргументов, весь NativeDisplay, blend/filter bits, косвенные
обходы, shader semantics, render-to-texture и соответствие пикселей новому
бэкенду остаются открыты. Измеренное окно раннего Adventure не заменяет плотные
волны/roof/fog. Нет оценки затрат в днях и нет обещания исправить Zombiquarium.

Counter stack покрывает выбранные Graphics entries, а не inline/uninstrumented
методы. Входы в старые hooks считаются до возможного подавления портом;
прямые вызовы `__imp__` их обходят. Частоты зависят от сцены и текущих исправлений
порта. CPU overhead проб отдельно не измерен, измерения не доказывают FPS нативного backend.

Исследовательские помощники приведены в документе, чтобы игнорируемый research
не стал невоспроизводимой зависимостью. Статусы и коммиты не менялись.

## 7. Вопросы к владельцу
