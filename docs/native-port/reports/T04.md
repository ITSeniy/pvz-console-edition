# T04 — раскладки Xbox, 17.10.2026

## 1. Итог

Описаны все приоритетные классы карточки: 12 раскладок (GamepadControls и
BaseGamepadControls раздельно), общий DataArray и три вида его слотов. В таблице
271 строка: 265 именованных полей и 6 полей object/id слотов. Каждое смещение имеет
адрес инструкции исходного Xbox; Android/PC-числа в заголовки не переносились.

Новый тест компилирует эти описания, общий CTest проходит **13/13**. Игровые хуки и
поведение не менялись. Это разреженные представления guest-байтов: неизвестные
участки оставлены pad, а неизвестный смысл проверенного слова — field/flag с
номером смещения. Полнота оригинальных C++-классов не заявляется.

## 2. Изменённые файлы

- `src/xbox/Types.h` — готовый `rex::be<T>` и GuestPtr = be<uint32_t>.
- `src/xbox/{LawnApp,Board,BaseGamepadControls,GamepadControls,SeedBank,SeedPacket,Plant,Zombie,Coin,Challenge,CursorObject,Widget}.h` — поля, пропуски и offsetof.
- `src/xbox/DataArray.h`, `src/xbox/DataArraySlots.h` — заголовок массива и граница
  payload/ID, без методов аллокации.
- `tests/xbox_layout_test.cpp` — только включения, static_assert и пустой main.
- `CMakeLists.txt` — четыре строки регистрации xbox_layout_test/xbox_layout;
  предшествующие изменения T05 сохранены.
- `docs/native-port/data/xbox-layouts.csv` — адреса и именованные функции для полей.
- этот отчёт — метод, проверка размеров, сверка уже используемых смещений и ограничения.

Ни один существующий `src/*.cpp` этим исполнителем не редактировался. Параллельная
T02 добавляла комментарии и свою карту имён. README, проверки scripts/check_*,
реплеи, generated, .cache, assets и исходные образы не изменялись этим исполнителем.
Коммитов и переключений веток нет.

## 3. Как воспроизвести

Из корня проекта:

```powershell
.\build.bat configure
.\build.bat --target xbox_layout_test
.\build.bat test
```

Собирать pvz/all для этой проверки не требуется. Выполненная сборка теста содержит
только компиляцию tests/xbox_layout_test.cpp и линковку xbox_layout_test.exe:
`research/cross-platform/t04/build-final.log`. Генератор гостевого кода не вызывался.
CTest: `research/cross-platform/t04/ctest-final.log`, SHA-256
`2c9c4e4e76071ab52a80926934d9220523f2f9de38633f2aeac665f795ffbe5a`.

Число строк и поля по классам:

```powershell
$t04Rows = Import-Csv docs/native-port/data/xbox-layouts.csv
$t04Rows.Count
$t04Rows | Group-Object class | Select-Object Name,Count
Get-FileHash docs/native-port/data/xbox-layouts.csv -Algorithm SHA256
```

Полностью воспроизводимый проверяющий скрипт приведён в приложении A этого отчёта;
его нужно сохранить как `research/cross-platform/t04/verify.py` и выполнить
`python -I research/cross-platform/t04/verify.py`. Он читает только локальные входы,
выдаёт SHA-256, дизассемблирует каждую строку CSV и повторяет буквальную сверку src.
Проверка адреса инструкции не заменяет ручную проверку происхождения this-регистра;
её аргументы приведены ниже.

Plant/Zombie/Coin здесь обозначают payload, который allocator конструирует и
очищает. ID массива вынесен в *Slot: шаг пула **не выдаётся за размер payload**.
Для BaseGamepadControls и Widget размер полного оригинального класса не
закреплён: заголовки описывают известный префикс, sizeof-assert полного класса
отсутствует сознательно. Их нельзя использовать как размер new.

Board.controls и Board.cursors: `8212C954..60` вычисляет `(player+6C)*4`,
`8212CAF4..CB00` — `(player+6E)*4`, player=0..1 (`8212CB84/8C`). Это +1B0/1B4
и +1B8/1BC, а не одиночные указатели. SeedBank.packets начинается addi this+50,
поэтому CSV ссылается на вычисление адреса, а не на lwz одного поля.

GamepadControls.target_x/target_y: ctor `82189FC4/CC` переносит два float одним
ld/std по +74; до этого на стеке два stfs (`82189FBC/C0`). Отдельные lfs/stfs в
именованном Update подтверждают float, несмотря на 64-битный перенос пары.
LawnApp.music_volume, напротив, один double +118, записанный stfd `821A0744`;
существующее чтение +118/+11C — два слова одного double.

## Приложение A. Самодостаточная проверка

```python
"""Run from repository root with python -I. Read-only inputs, hashed evidence."""
from pathlib import Path
import csv, hashlib, json, re, sys
root = Path.cwd()
sys.path.insert(0, str(root / 'tools/python'))
from capstone import Cs, CS_ARCH_PPC, CS_MODE_32, CS_MODE_BIG_ENDIAN
md = Cs(CS_ARCH_PPC, CS_MODE_32 | CS_MODE_BIG_ENDIAN)
image = root / '.cache/pvz-image.bin'
data = image.read_bytes()
rows = list(csv.DictReader((root / 'docs/native-port/data/xbox-layouts.csv').open()))
inputs = {str(p.relative_to(root)): hashlib.sha256(p.read_bytes()).hexdigest()
          for p in [image, root / 'docs/native-port/data/xbox-names.csv',
                    root / 'docs/native-port/data/xbox-layouts.csv',
                    root / 'tools/rexglue-sdk/win-amd64/include/rex/types.h']}
print(json.dumps({'inputs': inputs, 'rows': len(rows)}, indent=2))
for row in rows:
    a = int(row['evidence_address'], 16)
    ins = list(md.disasm(data[a-0x82000000:a-0x82000000+4], a))
    assert len(ins) == 1, row
    i = ins[0]
    print(f"{row['class']}.{row['field']} {row['offset']}: "
          f"{a:08X} {i.mnemonic} {i.op_str} -- {row['evidence_function']}")
aliases = {'app':'LawnApp', 'board':'Board', 'controls':'GamepadControls',
           'primary':'GamepadControls', 'bank':'SeedBank', 'packet':'SeedPacket',
           'cursor':'CursorObject', 'coin':'Coin', 'challenge':'Challenge',
           'plant':'Plant', 'zombie':'Zombie'}
sizes = {'GuestPtr':4, 'uint8_t':1, 'rex::be<uint32_t>':4,
         'rex::be<int32_t>':4, 'rex::be<float>':4, 'rex::be<double>':8,
         'DataArray':0x1C, 'SeedPacket':0x7C}
def span(row):
    m = re.fullmatch(r'(.+?)(?:\[(\d+)\])?', row['type'])
    return sizes[m[1]] * int(m[2] or 1)
uses = []
source_hashes = {}
for p in sorted((root / 'src').iterdir()):
    if p.suffix not in ['.h', '.cpp']: continue
    source_hashes[str(p.relative_to(root))] = hashlib.sha256(p.read_bytes()).hexdigest()
    for line, text in enumerate(p.read_text(encoding='utf-8-sig').splitlines(), 1):
        for m in re.finditer(r'\b([a-zA-Z_]\w*)\s*\+\s*(0x[0-9A-Fa-f]+|[0-9]+)\b',
                             text.split('//')[0]):
            base, literal = m.groups()
            cls = aliases.get(base)
            off = int(literal, 0)
            match = None
            if cls:
                match = next((r['field'] for r in rows if r['class'] == cls and
                    int(r['offset'], 0) <= off < int(r['offset'], 0) + span(r)), None)
            status = 'other class / scratch / host'
            if cls:
                status = 'matches' if match else ('derived Zen/Tree' if
                    cls == 'GamepadControls' and off in [0xF8, 0xFC] else 'UNRESOLVED')
            uses.append(dict(file=str(p.relative_to(root)), line=line, base=base,
                             offset=hex(off), class_=cls, field=match, status=status))
out = root / 'research/cross-platform/t04'
out.mkdir(parents=True, exist_ok=True)
(out / 'verified-offsets.json').write_text(json.dumps(
    {'inputs': inputs, 'source_hashes': source_hashes, 'uses': uses}, indent=2), encoding='utf-8')
print(json.dumps({'all':len(uses), 'priority':sum(u['class_'] is not None for u in uses),
                  'matched':sum(u['status']=='matches' for u in uses),
                  'unresolved':[u for u in uses if u['status']=='UNRESOLVED']}, indent=2))
```
