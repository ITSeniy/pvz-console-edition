# T02 — экспорт принятых имён Xbox

## 1. Итог

Принятая после T01b таблица экспортирована без пересмотра уверенности:
150 имён (7 high, 143 medium) доступны как константы C++ и как разметка Ghidra.
Скрипт действительно применён к сохранённому проекту Ghidra `T02Names`, затем
проект повторно открыт: все 150 имён сохранились. В существующем коде добавлен
один комментарий к high-хуку `Board::Draw`; код и поведение хуков не менялись.

## 2. Изменённые файлы

- `scripts/export_xbox_names.py` — воспроизводимый экспорт CSV, проверка SHA образа,
  диапазонов, уникальности адресов/идентификаторов; `--check` без записи.
- `src/xbox_names.h` — 150 `inline constexpr std::uint32_t` в `pvz::fn`, исходная
  сигнатура, уверенность и признаки сопоставления в комментариях.
- `src/mouse_bridge.cpp` — одна строка комментария перед `sub_82146A60`.
- `docs/native-port/reports/T02.md` — этот отчёт.

Пересоздаваемые результаты в игнорируемых каталогах:
`research/cross-platform/xbox-names.ghidra.py`, `xbox-names-export.json`;
доказательства запуска — `runtime-data/t02/`, проект —
`runtime-data/t02/projects/T02Names.gpr` и соседний `.rep`.
`generated/`, `config/analysis.toml`, исходные образы и README не редактировались.

## 3. Как воспроизвести

Из корня проекта:

```powershell
python -I scripts/export_xbox_names.py
python -I scripts/export_xbox_names.py --check
```

Скрипт читает CSV и образ; SHA-256 обоих входов помещает в каждый экспорт и
JSON-манифест. Несоответствие SHA образа свидетельству CSV останавливает экспорт.
Выгружаются только high/medium; low не повышаются. При одинаковом имени метода
суффикс формируется из всей сигнатуры (`Class_Draw_sig_int`,
`Class_Draw_sig_float`), при коллизии нормализованной записи добавляется хеш полной
сигнатуры. Реальных перегрузок среди этих 150 записей нет; две разные перегрузки
проверены синтетическим входом, включая обратный порядок строк.

Для реального применения использованы уже установленные Ghidra 12.1.2 и JDK 25.
Jython взят из штатного локального ZIP Ghidra, без загрузки и без изменения её
основных пользовательских настроек. Команды для нового имени проекта:

```powershell
$t02Ghidra = 'C:/Users/ITSeniy/ghidra_12.1.2_PUBLIC'
$t02Settings = "$PWD/runtime-data/t02/ghidra-settings"
$t02Ext = "$t02Settings/ITSeniy-ghidra/ghidra_12.1.2_PUBLIC/Extensions"
New-Item -ItemType Directory -Force $t02Ext, runtime-data/t02/projects | Out-Null
# Распаковывать однократно, если подпапки Jython ещё нет.
if (!(Test-Path "$t02Ext/Jython")) {
  Expand-Archive "$t02Ghidra/Extensions/Ghidra/ghidra_12.1.2_PUBLIC_20260605_Jython.zip" $t02Ext
}
$env:JAVA_HOME = 'C:/Program Files/Eclipse Adoptium/jdk-25.0.2.10-hotspot'
$env:GHIDRA_HEADLESS_JAVA_OPTIONS = "-Dapplication.settingsdir=$t02Settings"
& "$t02Ghidra/support/analyzeHeadless.bat" "$PWD/runtime-data/t02/projects" T02NamesRepeat `
  -import "$PWD/.cache/pvz-image.bin" -loader BinaryLoader -loader-baseAddr 0x82000000 `
  -processor PowerPC:BE:64:default -noanalysis `
  -scriptPath "$PWD/research/cross-platform" -postScript xbox-names.ghidra.py

# Проверка сохранённых имён после повторного открытия; файл только для чтения.
& "$t02Ghidra/support/analyzeHeadless.bat" "$PWD/runtime-data/t02/projects" T02NamesRepeat `
  -process pvz-image.bin -noanalysis -readOnly `
  -scriptPath "$PWD/research/cross-platform" -postScript xbox-names.ghidra.py
```

`ITSeniy-ghidra` — имя каталога настроек, выбранное установленной Ghidra на этой
машине. В другом окружении оно определяется её пользователем. Для уже созданного
проекта используется `-process`, а не повторный `-import` без `-overwrite`.

Перед изменением базы скрипт проверяет SHA-256 исходного исполняемого файла,
начало блока образа `82000000`, big endian и наличие всех диапазонов.
Если начало попадает внутрь другой функции, скрипт останавливается, ничего не
разрезая. Все изменения делаются в транзакции; посторонние комментарии сохраняются.
Полная сигнатура остаётся текстовой аннотацией, прототип ABI не придумывается.

## 5. Критерии приёмки

- **Выполнен:** заголовок отдельно компилируется без предупреждений;
  общий `build.bat test` после добавления параллельного теста T04 — 13/13 passed,
  exit 0 (`research/cross-platform/t04/ctest.log`; результат общего прогона T04).
- **Выполнен:** T02 меняет в существующем `src/` только один комментарий и создаёт
  заголовок. Проверка точного удаления добавленной строки даёт побайтовое совпадение
  `mouse_bridge.cpp` с HEAD после нормализации CRLF. Новые файлы T04 и существовавшие
  до T02 `render_probe.cpp`, `state_dump.cpp` к T02 не относятся.
- **Выполнен:** скрипт применён к `T02Names:/pvz-image.bin`, база сохранена и повторно
  открыта; примеры и полный вывод приведены выше.
- **Выполнен:** полный список проверки семи high-адресов приведён, противоречий 0.

## 6. Не проверено и риски

Medium остаются предположительными именами с признаками из принятой таблицы.
Экспорт не подтверждает ни точность всех этих имён, ни их прототипы/ABI. Для нового
Ghidra-проекта применяется точный raw-образ; импорт непосредственно `default.xex`
имеет другой SHA и намеренно не принимается этим вариантом скрипта.
Проверен Jython в Ghidra 12.1.2; отдельный запуск через PyGhidra не выполнялся.
Заголовок не подключён в игровую цель, кодген и журналирование игры не переименованы.
