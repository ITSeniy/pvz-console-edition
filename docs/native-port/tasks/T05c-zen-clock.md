# T05c. Часы Zen Garden и случайные раскладки в детерминированном режиме

**Этап:** инструменты проверки · **Зависит от:** T05b (принята, ещё в worktree) · **Объём:** малый · **Меняет поведение игры:** только под флагом

## Цель

Закрыть остаточный недетерминизм T05b и сделать зависящие от RNG регрессии стабильными.

## Что известно

- Zen: две пары расходятся с кадра 3130 только в `plants.state`/`plants.hash`; RNG совпадает.
  В PC-исходнике (`research/pvz-pc/Lawn/ZenGarden.cpp:745..827`, `:2232..2279`) состояния
  растений зависят от `_time64()`: окна полива 3 и 15 с, часовые потребности. Гипотеза:
  на Xbox так же используется системное время.
- `vases_pc_place_seed` (Feedback) зависит от раскладки ваз: `8215D4E0` → `8227AB40` →
  global Rand `82494380`. Seed по умолчанию берётся от времени запуска, поэтому тест
  проходит по везению.

## Что сделать

1. Найти Xbox-импорт или функцию времени, которую читает Zen Garden (кандидаты —
   `KeQuerySystemTime`, `NtQuerySystemTime`, обёртка CRT `time`). Подтвердить адресами
   вызовов из функций Zen Garden.
2. Под флагом `--pvz_deterministic_clock=<unix seconds>` выдавать время, которое
   продвигается от заданного значения строго по логическим шагам (1 шаг = 10 мс).
3. Повторить Zen-пару T05b: побайтно одинаковые снимки или найденная следующая причина.
4. Для `vases_pc_place_seed` и других сценариев с раскладкой от RNG предложить запуск с
   `--pvz_deterministic_seed` в `scripts/run_feedback_regression.ps1`. Сам скрипт без
   решения владельца не менять — описать предложение в отчёте.

## Результат

Дополнение `src/deterministic_replay.cpp` в worktree T05b, раздел в
`docs/native-port/state-dumps.md`, `docs/native-port/reports/T05c.md`.

## Критерии приёмки

- [ ] Источник времени Zen подтверждён адресами вызовов.
- [ ] Zen-пара побайтно совпадает на всём окне 5000 кадров, либо следующее расхождение описано с адресом.
- [ ] Без флагов поведение прежнее (хуки только вызывают оригинал — показать в отчёте).
- [ ] Список сценариев регрессий, зависящих от RNG, с предложенным seed.
